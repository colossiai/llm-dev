# AI + Finance Career Path

## 背景

> 理解了 LLM 核心之后, 作为金融系统研发工程师, AI+金融职业路方向怎么走?

非常好的转型时机。作为"金融系统研发工程师 + 懂 LLM 原理"的组合, 你其实站在一个**比纯算法工程师更稀缺**的位置。

---

## 你的核心竞争力

```
       懂 LLM 原理 (新技能)     ✓
              ×
       懂金融系统/业务流程 (老本钱) ✓
              ×
       工程能力 (扎实的代码能力)   ✓
       =
       AI 工程化方向的稀缺人才
```

**纯 ML 研究员**懂模型但不懂金融业务; **纯金融 IT**懂业务但不懂 AI。
**你的位置是"翻译层"**:把 AI 真正落地到金融场景的人。

---

## 方向选择(按上手难度排序)

### 🟢 立即可上手:**金融 LLM 应用工程师 / AI Agent 工程师**

不需要训练大模型, **调用 + 组装现成 LLM** 解决业务问题。

| 典型应用 | 技术栈 | 业务场景 |
|---------|--------|---------|
| 投研助手 | RAG + Agent + LLM API | 研报摘要、财报解读 |
| 合规审查 Agent | LangChain/AutoGen + 私有 LLM | 反洗钱、监管报告 |
| 智能客服/投顾 | RAG + Function Calling | 财富管理、产品咨询 |
| 信息提取 | LLM + 结构化输出 | 公告解析、新闻信号 |

**进入路径**:

- 学 LangChain / LlamaIndex / DSPy
- 学 vector DB (Milvus / Qdrant / pgvector)
- 学 Prompt 工程 + Tool Use / Function Calling
- 项目:在公司用 RAG 搭一个内部研报检索

→ **3-6 个月可独立交付项目, 薪资明显上涨**

---

### 🟡 6-12 个月深入:**AI 平台 / MLOps for Finance**

把 LLM 工程化、产品化、规模化 — **这是你最自然的方向**, 完美匹配你"系统研发"背景。

具体做的事:

- 公司内部 LLM 平台(模型管理、推理服务、监控)
- 私有化部署(金融行业基本不能用公网 API)
- 推理优化(vLLM、TGI、量化、KV Cache 优化)
- 多租户、合规审计、可解释性

技术栈:

```
LLM 推理: vLLM, TGI, Ollama, llama.cpp
微调:    LoRA, QLoRA, PEFT, unsloth
评估:    LangSmith, Phoenix, Promptfoo
监控:    模型漂移、prompt 注入检测
基础设施: K8s, GPU 调度, 推理网关
```

**国内典型雇主**:蚂蚁、字节、平安科技、招行金科、华泰证券技术、券商科技子公司。

---

### 🟠 1-2 年深入:**领域微调 / 金融大模型工程师**

用公司私有数据做模型微调(SFT、DPO、领域预训练)。

需要补:

- 训练框架 (DeepSpeed, FSDP, Megatron)
- 数据工程 (清洗、合成、质量评估)
- 评估方法 (针对金融任务的 benchmark)

参考项目:

- **FinGPT** (开源金融 LLM)
- **BloombergGPT** (闭源, 500 亿参数, 金融语料训练)
- **DISC-FinLLM** (复旦金融大模型)

→ 你 AI 背景需要更扎实, 但金融业务理解是巨大优势。

---

### 🔴 2-3 年挑战:**Quant + ML / 算法交易 ML 方向**

用 ML/LLM 做信号挖掘、因子生成、策略评估。

**门槛**:

- 金融工程数学(随机过程、衍生品定价)
- 时序建模(不是 LLM 那种)
- 强化学习
- 海量历史数据回测系统

**回报极高, 门槛也极高**。如果你对数学/统计有强兴趣可以走;否则不建议跳过工程化直接进。

国内雇主:幻方、明汯、九坤、稳博、World Quant 中国、各券商自营。

## 具体下一步(3 个动作)

### 1. 在公司启动一个 RAG 小项目(2 周内)

- 选一个高频痛点:研报检索、合规问答、内部知识库
- 用 LangChain + 公司选定的 LLM(私有部署 Qwen / DeepSeek)+ pgvector
- 目标:**让真实业务方用上**, 哪怕只是 demo
- → 工作成果 + 简历亮点

### 2. 学三套关键技术(3 个月)

- **RAG**:Embedding 模型、chunking 策略、reranker
- **Agent**:Tool use、ReAct、function calling、多步规划
- **私有部署**:vLLM 推理、模型量化(GGUF/GPTQ)、并发调优

### 3. 关注金融 AI 社区

- **国内**:雪球量化板块、机器之心、CSDN AI+金融、研报数据库 Wind/同花顺技术博客
- **国外**:HuggingFace 金融模型、FinGPT GitHub、Bloomberg Engineering blog
- **公司**:DeepSeek、Moonshot、智谱、Anthropic 的金融案例

---

## 避坑提醒

1. **别一头扎进训练大模型**:这是 99% 公司不会做的事(成本太高), 你的精力应该花在"用好"模型, 不是"造"模型。
2. **别低估金融业务理解的稀缺性**:很多 AI 工程师转金融失败就是因为不懂 T+1、不懂监管、不懂账户结构。**你这部分是金子**。
3. **别忽视合规和私有化**:金融行业 80% 的 AI 项目卡在数据出境、可解释性、监管审查上。**懂这些 = 别人无法替代你**。
4. **别只会 prompt engineering**:这是初级技能, 3 年后大模型会替代它。要往**系统能力**走(平台、评估、监控)。

---

## 一句话总结

> **走"AI 工程化 + 金融领域"路线, 不走"纯算法研究"路线。**
> 你的优势是"把 LLM 真正落地到金融业务"的能力 — 这是稀缺、长青、且不会被卷掉的位置。
>
> **第一步**:在公司启动一个 RAG 落地项目, 把"懂 LLM 原理"变成"做出过有人用的 LLM 产品"。
