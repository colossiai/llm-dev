# 机器学习基础知识点


下面是**机器学习（Machine Learning）基础知识点的系统整理**，适合入门学习（也适合你后续学习 LLM / 深度学习做铺垫）。

---

# 一、机器学习是什么

机器学习的核心思想是：

> 让模型从数据中学习规律，而不是人手写规则。

形式化一点：

* 输入：数据 ( X )
* 输出：预测 ( Y )
* 目标：学习函数 ( f(X) \approx Y )

---

# 二、三大基本类型

## 1. 监督学习（Supervised Learning）

有“标准答案”

* 输入：特征 + 标签
* 输出：预测标签

### 常见任务：

* 分类（Classification）

  * 垃圾邮件 / 非垃圾邮件
* 回归（Regression）

  * 房价预测

### 常见模型：

* Linear Regression
* Logistic Regression
* Decision Tree
* SVM
* Neural Network

---

## 2. 无监督学习（Unsupervised Learning）

没有标签

### 常见任务：

* 聚类（Clustering）

  * K-Means
* 降维（Dimensionality Reduction）

  * PCA

### 用途：

* 用户分群
* 数据压缩
* 特征学习

---

## 3. 强化学习（Reinforcement Learning）

通过“奖励”学习

* Agent（智能体）
* Environment（环境）
* Reward（奖励）

典型应用：

* 游戏 AI（AlphaGo）
* 机器人控制
* 推荐系统策略优化

---

# 三、机器学习基本流程

1. 收集数据
2. 数据清洗（缺失值、异常值）
3. 特征工程（Feature Engineering）
4. 选择模型
5. 训练模型
6. 评估模型
7. 调参优化
8. 部署上线

# 四、核心数学基础

## 1. 线性代数

* 向量、矩阵
* 矩阵乘法
* 特征值 / 特征向量

# 五、核心概念（非常重要）

## 1. Loss Function（损失函数）

衡量“预测有多错”

常见：

* MSE（均方误差）
* Cross-Entropy（交叉熵）

---

## 2. Optimization（优化）

目标：最小化 loss

方法：

* Gradient Descent
* SGD（随机梯度下降）
* Adam（深度学习常用）

---

## 3. Overfitting / Underfitting

* 过拟合：训练集很好，测试集很差
* 欠拟合：模型太简单，学不会规律

解决方法：

* 正则化（L1 / L2）
* Dropout
* 更多数据
* 简化模型

---

## 4. Bias-Variance Tradeoff

* Bias：模型偏差（太简单）
* Variance：模型波动（太复杂）

目标：平衡两者

---

# 六、模型评估指标

## 分类任务：

* Accuracy（准确率）
* Precision（精确率）
* Recall（召回率）
* F1 Score

## 回归任务：

* MSE
* MAE

---

# 七、特征工程（非常关键）

包括：

* 标准化（Standardization）
* 归一化（Normalization）
* 类别编码（One-hot encoding）
* 特征选择

👉 传统 ML 很依赖这一部分

---

# 八、机器学习 vs 深度学习

| 机器学习   | 深度学习   |
| ------ | ------ |
| 依赖特征工程 | 自动学习特征 |
| 模型较简单  | 神经网络   |
| 数据需求较小 | 需要大量数据 |

---

# 九、和 LLM 的关系（你很可能关心）

LLM 本质是：

> 深度学习 + Transformer + 大规模数据 + 自监督学习

你后面需要重点补：

* 神经网络
* 反向传播
* Softmax
* Attention
* Cross Entropy
* Embedding

---

# 十、学习路线建议（很重要）

如果你目标是 LLM / AI：

1. Python + Numpy
2. 线性代数 + 概率基础
3. 机器学习基础（本页内容）
4. 神经网络
5. PyTorch
6. Transformer / Attention
7. LLM（GPT结构）
