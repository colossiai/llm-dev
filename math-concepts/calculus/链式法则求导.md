```
y_pred = w * x
loss = (y_pred - y) ^ 2
求 导数d(loss)/d(w) 
```

---

给定：

```math
y_{\text{pred}} = wx
```

```math
loss = (y_{\text{pred}} - y)^2
```

要求：

```math
\frac{d(loss)}{dw}
```

---

### 第一步：代入 $(y_{\text{pred}})$

```math
loss = (wx - y)^2
```

---

### 第二步：应用链式法则

令：

```math
u = wx - y
```

则：

```math
loss = u^2
```

根据链式法则：

```math
\frac{d(loss)}{dw}
=
\frac{d(loss)}{du}
\cdot
\frac{du}{dw}
```

---

### 第三步：分别求导

#### 对 (u^2) 求导

```math
\frac{d(loss)}{du}
=
2u
```

#### 对 (wx-y) 求导

因为 (x) 和 (y) 是常数：

```math
\frac{du}{dw}
=
x
```

---

### 第四步：合并

```math
\frac{d(loss)}{dw}
=
2u \cdot x
```

代回 (u = wx-y)：

```math
\boxed{
\frac{d(loss)}{dw}
=
2(wx-y)x
}
```

---

### 数值例子

假设：

```math
x = 2,\quad y = 10,\quad w = 3
```

前向传播：

```math
y_{\text{pred}} = 3 \times 2 = 6
```

```math
loss = (6-10)^2 = 16
```

梯度：

```math
\frac{d(loss)}{dw}
=
2(6-10)\times 2
=
-16
```

即：

```math
\boxed{
\frac{d(loss)}{dw}=-16
}
```

梯度为负数，说明当前 (w) 太小了。

梯度下降更新：

```math
w_{\text{new}}
=
w-\eta\frac{d(loss)}{dw}
```

若学习率 (\eta=0.1)：

```math
w_{\text{new}}
=
3-0.1(-16)
=
4.6
```

可以看到 (w) 从 3 增加到 4.6，预测值会更接近真实值 10。

---

从反向传播角度看：

```math
w
\rightarrow
y_{\text{pred}}=wx
\rightarrow
loss=(y_{\text{pred}}-y)^2
```

梯度沿着计算图反向流动：

```math
\frac{d(loss)}{dw}
=
\frac{d(loss)}{d(y_{\text{pred}})}
\cdot
\frac{d(y_{\text{pred}})}{dw}
```

其中：

```math
\frac{d(loss)}{d(y_{\text{pred}})}
=
2(y_{\text{pred}}-y)
```

```math
\frac{d(y_{\text{pred}})}{dw}
=
x
```

因此：

```math
\boxed{
\frac{d(loss)}{dw}
=
2(y_{\text{pred}}-y)x
}
```

这正是神经网络反向传播中最基本的链式法则例子。

---

原式：

```math
loss = (wx-y)^2
```

展开：

```math
loss = w^2x^2 - 2wxy + y^2
```

因为 (x) 和 (y) 都是常数，所以对 (w) 求导：

```math
\frac{d(loss)}{dw}
=
\frac{d(w^2x^2)}{dw}
-
\frac{d(2wxy)}{dw}
+
\frac{d(y^2)}{dw}
```

分别计算：

```math
= 2wx^2 - 2xy + 0
```

提取公因子：

```math
= 2x(wx-y)
```

即：

```math
\boxed{
\frac{d(loss)}{dw}
=
2x(wx-y)
}
```

与链式法则得到的结果：

```math
\boxed{
\frac{d(loss)}{dw}
=
2(wx-y)x
}
```

完全相同。

---

为什么神经网络里更喜欢链式法则，而不是展开？

对于这个简单例子：

```math
(wx-y)^2
```

展开当然没问题。

但假设是一个三层神经网络：

```math
z_1=w_1x
```

```math
a_1=\sigma(z_1)
```

```math
z_2=w_2a_1
```

```math
loss=(z_2-y)^2
```

如果全部展开，会变成：

```math
(w_2\sigma(w_1x)-y)^2
```

再往深一点：

```math
(w_3\sigma(w_2\sigma(w_1x))-y)^2
```

很快就会变得极其复杂，甚至无法手工展开。

反向传播的思路是：

```math
\frac{d(loss)}{dw_1}
=
\frac{d(loss)}{dz_2}
\cdot
\frac{dz_2}{da_1}
\cdot
\frac{da_1}{dz_1}
\cdot
\frac{dz_1}{dw_1}
```

每一层只负责自己的局部导数，然后把梯度传下去。

这也是为什么：

* 数学上：展开求导和链式法则等价；
* 工程上：深度神经网络只能依靠链式法则（反向传播）高效计算梯度。

实际上，像 PyTorch 和 TensorFlow 的自动求导系统，本质上就是在计算图上自动应用链式法则，而不是先把整个表达式展开再求导。
