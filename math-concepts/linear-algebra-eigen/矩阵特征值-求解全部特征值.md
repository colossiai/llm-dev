# det(A−λI)=0 就是求矩阵全部特征值的方法吗


是的，**对于有限维方阵（(n \times n) 矩阵）来说，**

```math
\boxed{\det(A-\lambda I)=0}
```

**就是求全部特征值的标准数学方法。**

不过，理解**为什么**要这样做，比记住公式更重要。

---

# 从定义推导

特征值的定义是：

```math
Av=\lambda v
```

其中

* (A)：矩阵
* (v\neq0)：特征向量
* (\lambda)：特征值

把右边移到左边：

```math
Av-\lambda v=0
```

因为

```math
Iv=v
```

所以可以写成

```math
Av-\lambda Iv=0
```

提出 (v)：

```math
(A-\lambda I)v=0
```

现在问题变成：

> **什么时候一个矩阵乘以一个非零向量，会得到零向量？**

---

# 普通矩阵不会发生

例如

```math
\begin{bmatrix}
2&0\\
0&3
\end{bmatrix}
```

乘任何非零向量，都不会得到

```math
\begin{bmatrix}
0\\
0
\end{bmatrix}
```

为什么？

因为这个矩阵可逆。

可逆矩阵没有非零解。

---

# 什么时候才有非零解？

对于线性方程组

```math
Mx=0
```

有一个重要定理：

> **只有当矩阵 (M) 不可逆时，才存在非零解。**

而矩阵不可逆的充要条件就是：

```math
\boxed{\det(M)=0}
```

这里令

```math
M=A-\lambda I
```

于是得到

```math
\boxed{\det(A-\lambda I)=0}
```

这就是为什么要求行列式为零。

---

# 为什么它能找到全部特征值？

因为

```math
\det(A-\lambda I)
```

实际上是一个关于 (\lambda) 的多项式。

例如

二维矩阵：

```math
A=
\begin{bmatrix}
4&1\\
2&3
\end{bmatrix}
```

那么

```math
\det(A-\lambda I)
```

展开以后就是

```math
\lambda^2-7\lambda+10
```

解它：

```math
(\lambda-5)(\lambda-2)=0
```

得到

```math
\lambda=5,\quad2
```

这两个就是全部特征值。

---

# 三维也是一样

例如

```math
3\times3
```

矩阵。

最后得到的是

三次多项式：

```math
\lambda^3+a\lambda^2+b\lambda+c=0
```

解出三个根：

```text
λ₁
λ₂
λ₃
```

就是全部特征值。

---

# n×n 呢？

对于

```math
n\times n
```

矩阵，

得到的是

```math
n
```

次多项式：

```math
\det(A-\lambda I)
```

称为：

> **特征多项式（Characteristic Polynomial）**

它最多有

```math
n
```

个根（按重数计算）。

因此：

> 一个 (n\times n) 矩阵最多有 (n) 个特征值（允许重复；如果考虑复数域，则一定有 (n) 个根，按代数重数计算）。

---

# 一个容易误解的地方

很多初学者会问：

> 为什么不是直接求 (Av=\lambda v)？

其实本质上就是在求这个方程。

只是：

未知数有

* (v)
* (\lambda)

两个。

如果直接求，会变成非线性方程组，非常难。

数学家想到：

先利用

```math
(A-\lambda I)v=0
```

判断什么时候存在非零解。

于是先求

```math
\lambda
```

再回代求

```math
v
```

整个问题就简单得多。

---

## 实际计算中都是这样吗？

理论上，是的。

但在实际应用中（例如 Python、MATLAB、数值计算库），**几乎不会真的先展开**

```math
\det(A-\lambda I)
```

**再求根**。

原因是：

* 大矩阵展开行列式的计算成本高；
* 求高次多项式的根数值稳定性较差。

实际软件通常采用更高效、更稳定的数值算法，例如 QR algorithm、Power iteration、Lanczos algorithm 等来直接计算特征值。

---

## 一句话总结

* **数学定义**：(Av=\lambda v)。
* **理论求法**：把它变形为 ((A-\lambda I)v=0)，再利用“非零解存在当且仅当矩阵不可逆”，得到
  ```math
  \boxed{\det(A-\lambda I)=0.}
  ```
* **理论上**，解这个特征多项式可以得到矩阵的全部特征值。
* **工程实践中**，大型矩阵通常使用专门的数值算法，而不是直接计算行列式。
