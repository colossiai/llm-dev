# 介绍 ln(x)


`ln(x) 表示“要把 e 提升到多少次方，才能得到 x` : 

如果 $\ln(x) = y$

那么 $e^y$ = x, 即 $e^{ln(x)} = x$


## 证明 ln(ab) = ln(a) + ln(b)




```math

{\Huge

\begin{aligned}

e^{\ln(ab)}
&=ab\\
&=e^{ln(a)} \cdot e^{ln(b)}\\
&=e^{ln(a) + ln(b)}\\

\end{aligned}

}

```

所以

```math
{\Huge

\begin{aligned}

\ln(ab) = ln(a) + ln(b)

\end{aligned}

}

```

同理

```math
{\Huge

\begin{aligned}

\ln(a/b) = ln(a) - ln(b)

\end{aligned}

}

```
