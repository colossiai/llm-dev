# 指数和对数的导数公式（初学者版）

## 一句话总结

> **指数函数求导后还是自己（乘上一个系数），对数函数求导后会变成 $1/x$。**

这两类函数在机器学习里无处不在（softmax、交叉熵、sigmoid、似然函数），所以它们的导数公式是必须掌握的"工具锤"。

---

## 一、四个核心公式（先记结论）

| 函数 | 导数 | 备注 |
|------|------|------|
| $e^x$ | $e^x$ | 最特殊，导数=自己 |
| $a^x$ | $a^x \ln a$ | 多一个常数系数 $\ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ | 最干净的对数 |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ | 多一个 $\dfrac{1}{\ln a}$ |

**记忆口诀**：
- 指数求导：**自己 × ln(底数)**，所以 $e^x$ 因为 $\ln e = 1$，导数还是自己
- 对数求导：**$\dfrac{1}{x \cdot \ln a}$**（$a$ 为底数），所以 $\ln x$ 因为 $\ln e = 1$，导数是 $\dfrac{1}{x}$

> **直觉**：底数为 $e$ 时一切都最简单，这就是为什么数学和深度学习都偏爱 $e$。

---

## 二、什么是 $e$？（先理解这个常数）

$e \approx 2.71828\ldots$，它的定义是：

```math
e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n
```

**类比（银行复利）**：
- 你存 1 元，年利率 100%，一年后变 2 元
- 如果每半年复利一次：$\left(1 + \frac{1}{2}\right)^2 = 2.25$
- 如果每天复利：$\left(1 + \frac{1}{365}\right)^{365} \approx 2.7146$
- 如果"每一瞬间"都复利（连续复利）：极限就是 $e \approx 2.71828$

**关键性质**（这个就是后面所有推导的核心）：

```math
\lim_{h \to 0} \frac{e^h - 1}{h} = 1
```

> 直觉：当 $h$ 非常小时，$e^h \approx 1 + h$，所以 $\dfrac{e^h - 1}{h} \approx \dfrac{h}{h} = 1$。 (gpt: 这是Taylor展开)

---

## 三、$e^x$ 的导数推导（最重要的一个）

### 从导数定义出发

导数的定义是：

```math
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
```

代入 $f(x) = e^x$：

```math
(e^x)' = \lim_{h \to 0} \frac{e^{x+h} - e^x}{h}
```

### 把 $e^x$ 提出来

利用指数法则 $e^{x+h} = e^x \cdot e^h$：

```math
= \lim_{h \to 0} \frac{e^x \cdot e^h - e^x}{h} = \lim_{h \to 0} \frac{e^x(e^h - 1)}{h}
```

由于 $e^x$ 不含 $h$，可以提到极限符号外面：

```math
= e^x \cdot \lim_{h \to 0} \frac{e^h - 1}{h}
```

### 使用关键性质

前面说过 $\lim_{h \to 0} \dfrac{e^h - 1}{h} = 1$，所以：

```math
\boxed{(e^x)' = e^x \cdot 1 = e^x}
```

> **一句话**：$e^x$ 是唯一一个"导数等于自己"的函数（不算常数 0），这就是它的魔法。

---

## 四、$a^x$ 的导数推导

### 技巧：把任意底数转成 $e$

任何 $a^x$ 都可以写成 $e^{\text{something}}$：

```math
a^x = e^{\ln(a^x)} = e^{x \ln a}
```

> 类比：就像把"美元"换算成"人民币"再计算，所有指数都先翻译成"$e$ 语言"。

### 用链式法则求导

设 $u = x \ln a$，则 $a^x = e^u$，应用链式法则：

```math
(a^x)' = (e^u)' = e^u \cdot u'
```

其中 $u' = \ln a$（因为 $\ln a$ 是常数），$e^u = e^{x \ln a} = a^x$，所以：

```math
\boxed{(a^x)' = a^x \cdot \ln a}
```

### 验证

当 $a = e$ 时，$\ln e = 1$，所以 $(e^x)' = e^x \cdot 1 = e^x$ ✓

---

## 五、$\ln x$ 的导数推导

### 技巧：利用反函数关系

$y = \ln x$ 等价于 $x = e^y$，两边对 $x$ 求导：

```math
\frac{d}{dx}(x) = \frac{d}{dx}(e^y)
```

左边 $= 1$，右边用链式法则：

```math
1 = e^y \cdot \frac{dy}{dx}
```

解出 $\dfrac{dy}{dx}$：

```math
\frac{dy}{dx} = \frac{1}{e^y} = \frac{1}{x}
```

（因为 $e^y = x$）

```math
\boxed{(\ln x)' = \frac{1}{x}}
```

> **直觉**：$\ln x$ 增长得越来越慢（$x$ 越大，函数曲线越平），所以导数（斜率）随 $x$ 增大而减小，正好就是 $\dfrac{1}{x}$。

---

## 六、$\log_a x$ 的导数推导

### 技巧：换底公式

```math
\log_a x = \frac{\ln x}{\ln a}
```

由于 $\ln a$ 是常数，求导时直接提出来：

```math
(\log_a x)' = \frac{1}{\ln a} \cdot (\ln x)' = \frac{1}{\ln a} \cdot \frac{1}{x}
```

```math
\boxed{(\log_a x)' = \frac{1}{x \ln a}}
```

### 验证

当 $a = e$ 时，$\ln e = 1$，所以 $(\log_e x)' = (\ln x)' = \dfrac{1}{x}$ ✓

---

## 七、对比总览

| 函数 | 导数 | 推导用到的关键工具 |
|------|------|---------------------|
| $e^x$ | $e^x$ | 极限定义 + $\lim_{h\to 0}\frac{e^h-1}{h}=1$ |
| $a^x$ | $a^x \ln a$ | $a^x = e^{x\ln a}$ + 链式法则 |
| $\ln x$ | $\dfrac{1}{x}$ | 反函数 $x = e^y$ + 隐函数求导 |
| $\log_a x$ | $\dfrac{1}{x\ln a}$ | 换底公式 $\log_a x = \frac{\ln x}{\ln a}$ |

## 八、常见的"组合"形式（带链式法则）

实际题目里很少直接给你 $e^x$，更多是 $e^{2x}$、$e^{-x^2}$ 这种复合形式。

### 通用公式

| 复合形式 | 导数 |
|----------|------|
| $e^{f(x)}$ | $e^{f(x)} \cdot f'(x)$ |
| $a^{f(x)}$ | $a^{f(x)} \cdot \ln a \cdot f'(x)$ |
| $\ln f(x)$ | $\dfrac{f'(x)}{f(x)}$ |
| $\log_a f(x)$ | $\dfrac{f'(x)}{f(x) \ln a}$ |

### 例子 1：$\left(e^{2x}\right)'$

设 $f(x) = 2x$，$f'(x) = 2$：

```math
\left(e^{2x}\right)' = e^{2x} \cdot 2 = 2e^{2x}
```

### 例子 2：$\left(e^{-x^2}\right)'$（高斯函数）

设 $f(x) = -x^2$，$f'(x) = -2x$：

```math
\left(e^{-x^2}\right)' = e^{-x^2} \cdot (-2x) = -2x \cdot e^{-x^2}
```

### 例子 3：$\left(\ln(x^2+1)\right)'$

```math
\left(\ln(x^2+1)\right)' = \frac{(x^2+1)'}{x^2+1} = \frac{2x}{x^2+1}
```

## 九、在 LLM/深度学习里的用处

| 场景 | 用到的公式 |
|------|-----------|
| **Softmax 反向传播** | $(e^x)' = e^x$ |
| **Sigmoid 求导** | $\sigma(x) = \dfrac{1}{1+e^{-x}}$ 涉及 $e^{-x}$ 求导 |
| **交叉熵损失 (Cross Entropy)** | $\ln$ 求导 → $\dfrac{1}{x}$ |
| **极大似然估计 (MLE)** | 取 $\log$ 把乘积变求和后求导 |
| **KL 散度** | $\ln \dfrac{p}{q}$ 求导 |

> **一句话**：你看到的所有"loss 的梯度"公式里，几乎都藏着这四个导数公式。

---

## 十、最后总结

```
指数求导：自己 × ln(底数)
对数求导：1 / (x × ln(底数))
```

- $e$ 之所以特殊，是因为 $\ln e = 1$，让两类公式都退化成最简形式
- 理解了 $e^x$ 和 $\ln x$，其他底数都通过"换成 $e$"来推导
- 复合函数（$e^{f(x)}$、$\ln f(x)$）只需在基础公式上**乘以 $f'(x)$**（链式法则）

> 把这张表贴墙上，下次看到 softmax 反向传播就不会慌了。
