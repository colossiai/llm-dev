# 解释 np.linalg.eig


`np.linalg.eig` 是 **NumPy** 用来计算**矩阵特征值（Eigenvalues）和特征向量（Eigenvectors）**的函数。

如果你前几天刚学完 **行列式（det）**、**矩阵秩（rank）**、**矩阵逆（inverse）**，那么 `eig` 就是下一步最重要的内容之一，因为它几乎贯穿了 **机器学习、PCA、Google PageRank、金融、物理、图像处理** 等领域。

---

# 函数定义

```python
import numpy as np

eigenvalues, eigenvectors = np.linalg.eig(A)
```

返回两个东西：

```
eigenvalues   # 特征值 λ
eigenvectors  # 每一列都是对应的特征向量
```

例如

```python
import numpy as np

A = np.array([
    [2, 1],
    [1, 2]
])

values, vectors = np.linalg.eig(A)

print(values)
print(vectors)
```

输出类似

```python
[3. 1.]

[[ 0.7071 -0.7071]
 [ 0.7071  0.7071]]
```

---

# 返回值是什么意思？

## 第一项：eigenvalues

```
[3. 1.]
```

表示矩阵有两个特征值

```
λ₁ = 3

λ₂ = 1
```

---

## 第二项：eigenvectors

```
[[ 0.7071 -0.7071]
 [ 0.7071  0.7071]]
```

很多初学者这里都会看错。

**注意：每一列(column)才是一个特征向量。**

不是每一行。

所以：

第一列

```
[
0.7071
0.7071
]
```

对应

```
λ = 3
```

第二列

```
[
-0.7071
 0.7071
]
```

对应

```
λ = 1
```

NumPy 官方规定：

```
vectors[:, i]
```

就是

```
values[i]
```

对应的特征向量。

例如

```python
values[0]
```

得到

```
3
```

对应

```python
vectors[:,0]
```

得到

```
[
0.7071
0.7071
]
```

# 为什么叫特征向量？

因为它满足

```
A v = λ v
```

也就是

```
矩阵 × 向量
=
向量只被放大或缩小
```

方向完全不变。

例如

```
v
↓

|
|
|
```

经过矩阵以后

```
3v
↓

|
|
|
|
|
|
```

方向没有变。

这就是特征向量。

# 为什么有多个特征值？

二维矩阵通常有两个。

因为要求的是

```
det(A−λI)=0
```

这是一个二次方程。

例如

```
λ²−4λ+3=0
```

解出来

```
λ=1

λ=3
```

所以有两个特征值。

每个特征值都有对应的方向。

---

# NumPy 为什么返回两个对象？

因为：

```
特征值
```

告诉你

**缩放多少倍**

而

```
特征向量
```

告诉你

**沿哪个方向。**

例如

```
λ = 5
```

说明

```
这个方向被放大5倍
```

```
λ = 0.2
```

说明

```
这个方向缩小到20%
```

```
λ = -3
```

说明

```
翻转方向，再放大3倍
```

# 一个完整示例

```python
import numpy as np

A = np.array([
    [2, 1],
    [1, 2]
])

values, vectors = np.linalg.eig(A)

print("Eigenvalues:")
print(values)

print()

print("Eigenvectors:")
print(vectors)

print()

for i in range(len(values)):
    print(f"λ = {values[i]:.2f}")

    v = vectors[:, i]

    print("v =", v)

    print("A @ v =", A @ v)

    print("λ * v =", values[i] * v)

    print()
```

运行后可以看到，对于每一个返回的特征向量，都满足：

```
A @ v == λ * v
```

---

## 与 `np.linalg.eigh` 的区别

如果矩阵是**实对称矩阵**（例如协方差矩阵、相关矩阵），通常应使用：

```python
values, vectors = np.linalg.eigh(A)
```

它比 `eig` 更稳定、更高效，而且返回的特征值默认按升序排列。PCA、协方差分析等场景一般都使用 `eigh` 而不是 `eig`。

## 学习建议

结合我们之前讨论的线性代数学习路线，建议按这个顺序理解：

1. **矩阵表示线性变换**（矩阵把空间中的向量变换到另一个位置）
2. **矩阵乘向量**（理解变换过程）
3. **特征向量**（哪些方向经过变换后方向保持不变）
4. **特征值**（这些特殊方向被拉伸或压缩了多少倍）
5. **矩阵对角化**：如果矩阵有足够多的特征向量，可以写成
   ```math
   A = P D P^{-1}
   ```
   其中 (D) 是只包含特征值的对角矩阵。
6. **PCA、SVD、Attention** 等高级算法都会建立在这些概念之上。

对于学习 LLM 和深度学习来说，真正理解 `np.linalg.eig` 的意义，比记住函数用法更重要：它揭示了一个线性变换最本质的“天然方向”和“天然缩放比例”。


```
输出的j是什么意思

[3.+0.j 1.+0.j]
[[ 0.70710678+0.j -0.70710678+0.j]
 [ 0.70710678+0.j  0.70710678+0.j]]
```

这是一个非常好的问题，因为它引出了**复数（Complex Number）**，而**特征值/特征向量天然就是定义在复数域上的**。

---

你的输出是：

```python
[3.+0.j 1.+0.j]

[[ 0.70710678+0.j -0.70710678+0.j]
 [ 0.70710678+0.j  0.70710678+0.j]]
```

这里的

```python
0.j
```

表示

> **0 × i**（虚数部分为 0）

在 Python 中：

* 数学里的虚数单位写作 **i**
* Python 为了避免和变量名 `i` 冲突，使用 **j**

例如：

```python
3 + 4j
```

表示

[
3+4i
]

## 为什么 NumPy 会输出 `+0.j`？

因为 `np.linalg.eig()` **始终返回复数类型（complex）**。

即使你的矩阵只有实数，NumPy 也会返回：

```python
3 + 0j
```

而不是

```python
3
```

这样做是为了统一接口。

例如：

```python
A = np.array([
    [2,1],
    [1,2]
])

values, vectors = np.linalg.eig(A)

print(values.dtype)
```

输出：

```python
complex128
```

即使所有虚部都是 0。

---

## 为什么要这样设计？

因为并不是所有矩阵都有实数特征值。

例如：

```python
A = np.array([
    [0,-1],
    [1,0]
])
```

这是一个旋转 90° 的矩阵。

运行：

```python
values, vectors = np.linalg.eig(A)

print(values)
```

输出：

```python
[0.+1.j 0.-1.j]
```

也就是

[
\lambda_1=i
]

[
\lambda_2=-i
]

这两个都是**复数特征值**。

如果 NumPy 有时候返回 `float`，有时候返回 `complex`，程序就会变得难写，所以它统一返回 `complex`。

---

## 那我的矩阵为什么没有虚数？

你的矩阵是

```python
[[2,1],
 [1,2]]
```

它是一个**实对称矩阵（Real Symmetric Matrix）**。

这种矩阵有一个非常重要的性质：

> **所有特征值一定都是实数。**

所以：

```python
3+0j
```

其实就是

```python
3
```

以及

```python
0.7071+0j
```

就是

```python
0.7071
```

虚部只是碰巧等于 0。

---

## 如果只想要实数怎么办？

可以取实部：

```python
values.real
```

得到

```python
array([3., 1.])
```

或者：

```python
vectors.real
```

得到

```python
array([
 [ 0.7071, -0.7071],
 [ 0.7071,  0.7071]
])
```
