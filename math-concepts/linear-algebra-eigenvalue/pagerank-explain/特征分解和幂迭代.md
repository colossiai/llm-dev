# PageRank:为什么特征分解和幂迭代结果一样

> 对应代码:`math-concepts/linear-algebra-eigenvalue/pagerank-explain/pagerank_test.py`

---

## 一句话直觉

PageRank 的定义就是方程 `G @ r = r`(排名向量经过一轮"投票传播"后不变)。这正是**特征值 = 1 的特征向量**的定义。而幂迭代反复算 `r = G @ r`,最终会收敛到的那个"不动向量",数学上必然就是这个特征向量。**它们在求同一个解,只是路径不同。**

---

## 为什么幂迭代一定收敛到特征值=1 的特征向量

把初始向量 `r₀` 用 G 的特征向量 `v₁, v₂, ...`(对应特征值 `λ₁, λ₂, ...`)展开:

```
r₀ = c₁v₁ + c₂v₂ + c₃v₃ + ...
```

每乘一次 G,每个分量就被自己的特征值放大一次:

```
Gᵏ r₀ = c₁λ₁ᵏ v₁ + c₂λ₂ᵏ v₂ + c₃λ₃ᵏ v₃ + ...
```

关键在于 Google 矩阵的特征值满足:**最大特征值恰好 = 1,其余全部 `|λ| < 1`**(这由 `G` 列随机 + 阻尼系数 `DAMP` 保证)。

于是迭代次数 `k` 越大:

- `λ₁ᵏ = 1ᵏ = 1` → `v₁` 分量**原封不动保留**
- `λ₂ᵏ, λ₃ᵏ, ... → 0` → 其他分量**指数级衰减消失**

跑 100 轮后,除了 `v₁` 其他都被压没了,归一化后就剩下特征值=1 的特征向量本身。

---

## 两种方法对比

| | 特征分解法 (`np.linalg.eig`) | 幂迭代法 (循环 `G @ r`) |
|---|---|---|
| 在求什么 | `G@r = 1·r` 的解 | `r = G@r` 的不动点 |
| 求解方式 | 一次性解出**所有**特征值/向量,再挑 λ≈1 那个 | 只逼近**主特征向量**,反复迭代 |
| 代价 | O(n³),要存整个矩阵 | 每轮 O(边数),超省内存 |
| 适用规模 | 小矩阵(几百维) | 亿级网页(Google 真实用法) |
| 结果 | **同一个向量** | **同一个向量** |

---

## 类比

想象一个音箱同时放好几个音(每个音 = 一个特征向量)。每过一秒,只有一个音(λ=1)音量不变,其他音都在衰减。听得够久,你耳朵里只剩那个不衰减的音——那就是主特征向量。

- **特征分解**:直接用频谱仪把这个音的频率精确标出来。
- **幂迭代**:啥仪器不用,单纯"多等一会儿",让别的音自己消失。

殊途同归。

## 一个小提醒(工程细节)

代码里 `idx = np.argmin(np.abs(vals - 1.0))` 挑"最接近 1 的特征值"是对的,但 `np.linalg.eig` 返回的特征向量方向/符号是任意的(可能带负号或复数),所以用了 `np.abs(...)` 再归一化来对齐——这也是为什么两个结果能对上号。理论上如果某个特征向量本身有正有负,`abs` 会出错,但对 PageRank 的主特征向量(全正)是安全的。

## 实测:把全部特征值打印出来

在特征分解后加了两行:

```python
vals, vecs = np.linalg.eig(G)
print("全部特征值 vals =", vals)
print("特征值的模 |λ| =", np.abs(vals))
```

运行输出(关键部分):

```
特征值的模 |λ| = [1.0,   0.425,   0.425,   ~0,   ~0]
                 ↑最大    ↑其余全部 < 1
```

### 看这一行就够了

| 特征值 | 模 \|λ\| | 幂迭代跑 100 轮后 \|λ\|¹⁰⁰ | 命运 |
|---|---|---|---|
| **1.0** | 1.0 | `1¹⁰⁰ = 1` | **完整保留** ✅ |
| -0.425 | 0.425 | `0.425¹⁰⁰ ≈ 10⁻³⁷` | 衰减消失 |
| -0.425 | 0.425 | `≈ 10⁻³⁷` | 衰减消失 |
| ~10⁻¹⁹ | ~0 | ~0 | 早就没了 |
| ~10⁻¹⁷ | ~0 | ~0 | 早就没了 |

只有 λ=1 的分量能活下来,其他的乘 100 次后小到 `10⁻³⁷`,连浮点数都快表示不了了。所以幂迭代收敛到的,**只可能是**那个特征值=1 的特征向量。

### 结果对齐

两种方法给出**完全相同**的向量:

```
[0.3166, 0.2148, 0.2148, 0.2238, 0.03]
 A       B       C       D       E
```

排名:**A > D > B = C > E**,符合直觉——A 被最多页面链接,E 没人链接(只拿到阻尼保底的 0.03)。B 和 C 完全相等也合理:它们的入链结构对称(都被 A 和 D 指向)。

---

## 附带发现:收敛有多快?

主特征值 1 和第二大特征值 0.425 的差距(叫 **spectral gap,谱隙**)决定收敛速度。这里第二大才 0.425,差距很大,所以收敛极快——其实不用 100 轮,**20 轮左右就到小数点后 15 位了**。

真实 Google 矩阵的谱隙主要由阻尼系数 `DAMP=0.85` 控制,这也是为什么 Google 选 0.85 而不是更大:太接近 1 收敛会变慢。

---

## 一句话总结

**特征分解和幂迭代求的是同一个东西**(`Gr = r` 的解 = 特征值1 的特征向量);幂迭代靠"其他特征值 |λ|<1 会指数衰减"这一性质,不解全谱、只反复相乘就自动逼近它,因此省内存、能扩到亿级网页,这也是 Google 真实采用的算法。
