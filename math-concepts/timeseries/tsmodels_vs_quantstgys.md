# 量化交易策略 与 时间序列模型 的关系

> 配套 demo 见 [`demos/`](demos/);模型本身的讲解见 [`timeseries-models.md`](timeseries-models.md)。

学了 AR/MA/ARMA/ARIMA/GARCH/Kalman,关键一跳是:**怎么用到真实策略研发里?**
先给一个反直觉的结论:

> **这些经典模型在量化里,大多不是直接"按一下出买卖信号"的预测器。真正的 alpha 信号往往很弱;它们更多扮演"风控 / 仓位 / 状态估计 / 统计检验"的配角。而 trend-following 恰恰建立在"反 AR"的假设上。**

---

## 一、先分清两大策略家族:它们的统计假设是对立的

| | **趋势/动量 (Trend-following)** | **均值回复 (Mean-reversion)** |
| --- | --- | --- |
| 赌什么 | 涨了还会涨,趋势**持续** | 偏离了会**被拉回** |
| 收益的自相关 | **正**自相关(某些周期) | **负**自相关 |
| 对应模型假设 | 价格≈随机游走带漂移 (ARIMA d=1)、Hurst>0.5 | **AR(1) φ<1**、平稳、协整、OU 过程 |
| 典型实现 | 均线交叉、突破(Donchian)、时序动量 | 配对交易、统计套利、价差回归 |
| 谁是主场 | 期货 CTA、宏观 | 股票中性、做市、价差 |

**关键洞察:** demo 里的 `AR(1) φ<1` 是**均值回复**的数学本体,它是 trend-following 的**对立面**。所以 trend-following 不是"用 AR 预测",反而是赌"价格不满足平稳 AR、存在长程正相关 + 漂移"。

---

## 二、六个模型在量化研发流水线里的真实角色

一个完整策略 = **信号 → 仓位/风控 → 执行 → 回测检验**,模型分布在不同环节:

| 模型 | 在量化里的真实角色 | 和 trend-following 的具体关系 |
| --- | --- | --- |
| **AR / ARMA** | 信号(但主要给**均值回复**用) | 反向参照:TF 赌的是 AR 假设**不成立** |
| **ARIMA** | 基线/证伪工具 | ARIMA(0,1,0)=随机游走="不可预测";TF 赌漂移项与长记忆偏离它 |
| **差分/ADF/协整** | **统计检验**(选标的) | 配对交易必备;TF 里用来确认序列**非平稳**才值得追趋势 |
| **GARCH** | **仓位 sizing / 风控**(最实用!) | **波动率目标**:σ 大→减仓,σ 小→加仓。这是 CTA 提升夏普最关键的一步 |
| **Kalman** | **状态估计 / 自适应趋势** | 自适应均线、动态对冲比、实时估计"当前趋势斜率" |

---

## 三、重点:trend-following 到底怎么用到这些模型

经典趋势策略(双均线/突破)其实**不需要**复杂模型。但工程化、提升夏普时,这三处最常嵌入:

**1. Kalman = 更聪明的"均线"(信号侧)**
固定窗口均线有滞后。用状态空间的 **local linear trend 模型**(状态=水平+斜率),Kalman 给你一条**自适应、低滞后**的趋势线,斜率符号就是趋势方向。比固定 MA 更跟手。

**2. GARCH = 仓位控制(风控侧,性价比最高)**
TF 圈名言:*"It's the risk management, not the signal."*

```
仓位 ∝ 目标波动率 / GARCH预测的σ_t
```

波动聚集(GARCH demo 那张图)意味着 σ 可预测 → 高波动期自动缩仓,回撤显著降低。这是 managed futures 行业标配。

**3. 协整/ADF = 选标的(均值回复策略侧)**
配对交易前,先用 ADF/协整检验确认价差平稳,再用 AR(1)/OU 估计回复速度和半衰期决定持仓时长。

---

## 四、坦诚的现实(避免误区)

- **EMH 弱式有效**:价格极接近随机游走,纯 ARIMA 直接预测价格基本赚不到钱(ARIMA demo 里 ADF 也印证了)。
- 所以现代 alpha 越来越靠 **ML / 另类数据 / 微观结构**,经典时序模型退居**风控、特征工程、基础设施、归因**。
- 但它们是**基本功**:不懂平稳/自相关/波动聚集,连"为什么这个策略会失效"都说不清。

---

## 一句话总结

| 你想做 | 主要靠 |
| --- | --- |
| 趋势/动量信号 | Kalman 自适应趋势(+ 突破/动量逻辑),**反** AR 假设 |
| 控仓降回撤 | **GARCH 波动率目标**(最实用) |
| 均值回复/套利 | **AR(1)/OU + 协整/ADF** |
| 实时估计真值/对冲比 | Kalman |

> **信号靠逻辑+Kalman,活下来靠 GARCH 控仓,选标的靠平稳性检验,均值回复才是 AR 的主场。**
