# 金融时间序列模型 Demo (初学者版)

每个模型一个独立脚本: **直觉 → 公式 → 代码 → 画图**, 跑完看图就懂。
配套理论讲解见上层目录 [`../timeseries-models.md`](../timeseries-models.md)。

## 怎么跑

用 `uv` (脚本头部已内嵌依赖, 无需手动装包)。本机网络需要 `--native-tls`:

```bash
cd math-concepts/timeseries/demos
uv run --native-tls 01_ar.py      # 第一次会自动下载 numpy/statsmodels 等
```

每个脚本会:
1. 在终端打印**真值 vs 估计值**和一句话总结;
2. 在同目录生成同名 `.png` 三联图。

## 先看总览图

`00_overview.py` 把六个模型的"指纹"画在一张 2×3 大图里 (上排看 ACF 区分 AR/MA/ARMA,
下排看趋势/波动/状态)。**建议先跑它建立全局印象, 再逐个看细节:**

```bash
uv run --native-tls 00_overview.py
```

## 全景图: 6 个模型在解决什么问题

| 脚本 | 模型 | 一句话 | 预测对象 | 金融用途 |
| --- | --- | --- | --- | --- |
| `00_overview.py` | **总览** | 六模型指纹一图流 | — | 建立全局印象 |
| `01_ar.py` | **AR** 自回归 | 未来 = 过去**值**的加权和 (惯性) | 均值 | 均值回复、价差 |
| `02_ma.py` | **MA** 移动平均 | 未来 = 过去**冲击**的余波 | 均值 | 消化突发消息、微观噪声 |
| `03_arma.py` | **ARMA** | 惯性 + 冲击余波合体 | 均值 | 平稳收益率短期结构 |
| `04_arima.py` | **ARIMA** | 先**差分**去趋势, 再 ARMA | 均值 | 价格→收益率→预测 |

| `06_kalman.py` | **Kalman** | 噪声里**在线**估计真实状态 | 状态 | 实时公允价、动态对冲比 |

## 手写版 (不调库, 看清"参数怎么估出来")

上面的脚本用 statsmodels/arch 一行就拟合了。下面两个把那行拆开, 只用 numpy 亲手算估计:

| 脚本 | 内容 | 核心收获 |
| --- | --- | --- |
| `manual_ar.py` | OLS 正规方程 + Yule-Walker 两种解法 | **AR 是线性回归, 有闭式解 → 解方程就出 φ** |
| `manual_ma.py` | 矩估计 + 条件最小二乘 CSS (画 SSE(θ) 曲线) | **MA 的冲击 ε 看不见 → 没闭式解, 靠"试 θ + 残差最小"反推** |

一句话对比: **AR 解方程, MA 试钥匙** —— 区别就在"回归变量看不看得见"。

## 关系脉络 (建议按此顺序学)

```
基础预测 (预测"值")
  AR    用过去的值       ──┐
  MA    用过去的冲击     ──┼──► ARMA 两者结合
                          │
处理趋势                   │
  ARIMA = ARMA + 差分(I) ◄─┘    把不平稳拍平成平稳

处理风险 (预测"波动")
  GARCH 预测方差 σ_t²            波动聚集 + 厚尾

状态估计 (在线融合)
  Kalman 预测+更新两步循环       按不确定性加权融合 模型 与 观测
```

## 两组最容易混的对比 (重点)

**AR vs MA —— 看 ACF 指纹区分:**

| | 看什么 | 记忆 | ACF | PACF |
| --- | --- | --- | --- | --- |
| AR(p) | 过去的**值** | 无限 (衰减) | 拖尾 | lag=p 后**截断** |
| MA(q) | 过去的**冲击** | 有限 (q 步) | lag=q 后**截断** | 拖尾 |

**预测"值" vs 预测"波动" vs 估"状态":**

| | 代表 | 关心 | 适合 |
| --- | --- | --- | --- |
| 预测均值 | AR/MA/ARMA/ARIMA | 下一个值是多少 | 方向、点预测 |
| 预测方差 | GARCH | 波动有多大 (风险) | 风控、定价 |
| 估状态 | Kalman | 噪声背后的真值 | 实时系统 |

## 一句话记忆版

- **AR**: 过去**值**决定未来
- **MA**: 过去**冲击**决定未来
- **ARMA**: 两者都要
- **ARIMA**: 先去趋势再预测
- **GARCH**: 预测**波动有多大**
- **Kalman**: 在噪声里估**真实状态**
