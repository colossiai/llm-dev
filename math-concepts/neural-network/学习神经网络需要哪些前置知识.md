# 学习神经网络需要哪些前置知识


学习神经网络（Neural Network）并不需要先成为数学专家，但有一些前置知识会让学习过程顺畅很多。可以按下面的顺序学习。

## 1. Python 编程（必需）

神经网络和 LLM 目前主要使用 Python。

建议掌握：

* 变量、函数、类
* List、Dict
* for 循环
* 模块导入
* 文件读写
* 基本面向对象

例如：

```python
def square(x):
    return x * x

print(square(5))
```

---

## 2. NumPy 与张量（非常重要）

神经网络本质上是在处理大量数字矩阵。

需要理解：

* 向量（Vector）
* 矩阵（Matrix）
* 张量（Tensor）
* Shape
* Broadcasting
* Reshape
* Transpose

例如：

```python
import torch

x = torch.randn(32, 128)
```

表示：

* batch = 32
* feature = 128

你最近学习 Attention、MLP、Multi-head Attention，其实大部分难点都在张量维度理解。

---

## 3. 线性代数（核心）

神经网络本质：

```text
输入
 ↓
矩阵乘法
 ↓
激活函数
 ↓
矩阵乘法
 ↓
输出
```

需要掌握：

### 向量

### 矩阵

### 矩阵乘法

```math
y=Wx+b
```

重点掌握：

* Matrix Multiplication
* Dot Product
* Linear Transformation
* Transpose
* Eigenvector（了解即可）

学习到能理解：

```python
y = x @ W + b
```

即可。

---

## 4. 微积分（核心）

训练神经网络需要求导。

需要理解：

### 导数

rac{d}{dx}x^2=2x

意义：

> 参数变化一点点，结果变化多少。

### 链式法则（Chain Rule）

```math
\frac{dy}{dx}=\frac{dy}{du}\frac{du}{dx}
```

这就是 Backpropagation（反向传播）的数学基础。

不需要大学数学分析水平。

掌握：

* 导数
* 偏导数
* 链式法则

就足够学习深度学习。

---

## 5. 概率统计（重要）

LLM 本质上是在预测概率。

例如：

```text
I love eating __
```

模型输出：

```text
pizza   0.6
rice    0.2
apple   0.1
...
```

需要理解：

* 概率
* 条件概率
* 期望
* 方差

以及：

### Softmax

### Cross Entropy

这是 LLM 最核心的损失函数。

---

## 6. PyTorch（框架）

学完前面内容后进入 PyTorch。

重点：

* Tensor
* Autograd
* nn.Module
* Loss Function
* Optimizer

例如：

```python
import torch.nn as nn

model = nn.Linear(10, 1)
```

---

# 学习神经网络的推荐路线

对于你的情况（已经在学 Attention、Softmax、Cross Entropy）：

```text
Python
 ↓
NumPy / Tensor
 ↓
PyTorch基础
 ↓
线性代数
 ↓
微积分
 ↓
线性回归
 ↓
MLP
 ↓
Backpropagation
 ↓
CNN（了解）
 ↓
Transformer
 ↓
LLM
```

## 最小数学要求

如果目标是：

* 理解 GPT
* 阅读 Transformer 论文
* 手写 Attention
* 手写 MLP

那么只需要：

✅ 矩阵乘法
✅ 向量点积
✅ 导数
✅ 链式法则
✅ Softmax
✅ Cross Entropy

事实上，很多工程师就是靠这几项知识进入 LLM 领域的。

根据你最近的问题（Tensor Shape、Broadcasting、Softmax、Cross Entropy、Attention），你已经在「PyTorch 基础 → Transformer 原理」阶段了。下一步最值得深入的是：

1. Backpropagation（反向传播）
2. 自动求导 Autograd
3. 手写 Linear Regression
4. 手写 MLP
5. 手写 Single-Head Attention
6. Multi-Head Attention
7. Transformer Encoder/Decoder
8. GPT 的训练过程

这条路线会比较自然地衔接到 LLM。
