# 方差/标准差公式的来源

## 题外话:为什么标准差是这个公式?有什么历史原因或者数学优势?

标准差这个公式 `σ = √(mean((x-μ)²))` 看起来奇怪 —— 为什么要先减均值、再平方、再开方?

其实背后有 **3 个数学优势 + 2 段历史**。

---

## 公式的由来:逐步分解动机

### 第 1 步:`x - μ`(减均值)

为了衡量"偏离中心多远"。**任何度量"分散程度"的指标都要做这一步。**

但这里马上有个问题:`Σ(x - μ) = 0`(正负偏离会抵消)。

举例:`x = [8, 10, 12]`, μ = 10。
偏离 = `[-2, 0, +2]`, 直接求和 = 0, 看不出散度。

**所以必须把负号消掉。**

---

### 第 2 步:为什么是 `²` 而不是 `|·|`?

这是历史和数学的核心。有 **两个备选方案**:

| 方案 | 公式 | 叫什么 |
|------|------|------|
| A | `mean(|x - μ|)` | **MAD (平均绝对偏差)** |
| B | `mean((x - μ)²)` | **方差** |

两个都能消掉负号, 但最终大家选了 **B(平方)**。原因有 4 个:

---

### 优势 1:**可微分(数学最关键的理由)**

```
|x|  在 x=0 处不可导(有个尖角)
x²   处处光滑可导
```

→ 平方版本可以**直接做微积分、求导、做优化**(梯度下降的灵魂)。
→ ML 里的损失函数(MSE)直接用平方, 就是这个原因。
→ 绝对值版的损失也能用, 但要靠 subgradient 等技巧, 数学繁琐。

---

### 优势 2:**可加性(Variance is additive)**

这是统计学里**最重要**的优势:

```
独立随机变量:    Var(X + Y) = Var(X) + Var(Y)   ✓
                MAD(X + Y) ≠ MAD(X) + MAD(Y)   ✗
```

举例:抛 100 个硬币, 总和的方差 = 100 × 单次方差。
这是**中心极限定理**等核心结论的基础。

如果用 MAD, 这套数学完全崩溃, 统计学就建立不起来。

---

### 优势 3:**几何意义 = 欧氏距离(L2 范数)**

把数据看成空间中的点:

```
向量 (x₁, x₂, x₃) 到中心 (μ, μ, μ) 的距离
= √( (x₁-μ)² + (x₂-μ)² + (x₃-μ)² )
= N · σ
```

→ 标准差 = **数据点到"中心"的欧氏距离(归一化版)**

这意味着标准差和我们熟悉的"两点距离"是同一个东西, 所有几何/线性代数的工具都能套用(旋转、投影、SVD...)。

---

### 优势 4:**正态分布的天然参数**

如果数据服从正态分布 `N(μ, σ²)`, 那么:

- `(μ, σ²)` 完全确定了这个分布
- 用 MLE(最大似然)反向估计参数时, **自动会得到方差公式**

→ "平方"不是人为选的, 是**正态分布数学结构里浮现出来的**。

---

### 第 3 步:为什么最后要开方?

为了**单位匹配**!

```
x 的单位是"米"
方差 σ² 的单位是"米²"  ← 不直观, 米² 是面积...
开方后  σ 的单位是"米"  ← 和数据同单位, 能直接比较
```

举例:身高数据

- 方差 = 0.0025 m²(怪)
- 标准差 = 0.05 m = 5 cm(立刻能理解)

→ **方差适合数学推导, 标准差适合人类阅读和报告**。
LLM 里 LayerNorm 除以的就是 std(已开方), 而不是 var。

---

### 第 4 步:除以 N 还是 N-1?

```
总体方差: ÷ N      (population variance)
样本方差: ÷ N-1    (sample variance, Bessel 修正)
```

- `÷ N`:已知全体数据时用, 得到的就是"这堆数的"散度
- `÷ N-1`:从有限样本估计未知总体的方差时用, **是无偏估计**
- 直觉:用样本均值代替真实均值时引入了偏差, 扣 1 个自由度补偿

ML 里用哪个无所谓(数据量大, 1 的差别可忽略)。PyTorch 的 `var(unbiased=False)` 就是除 N。

---

## 两段历史

### Gauss 1809:从天文学诞生

天文学家 Gauss 想从有误差的观测里推算行星轨道。他假设:

> "误差出现的概率, 应该是误差大小的某个函数"

他从几个公理出发推导, 发现**只有正态分布 + 平方误差**能满足所有条件。
这就是著名的"**最小二乘法**"(Least Squares), 也是平方损失的源头。

→ 平方不是任意选的, 是**从最朴素假设里自动浮现的**。

### Pearson 1894:命名"Standard Deviation"

19 世纪人们其实用过 MAD、"概率误差(probable error)"等好几种指标, 概念混乱。
**Karl Pearson** 决定推一个"统一标准", 起名 **standard deviation**。
之所以"standard", 就是为了**统一行业**, 大家都用同一个度量。

---

## MAD 没死, 某些场景更好

| 场景 | 推荐 |
|------|------|
| 数据近似正态、要做推断、要做优化 | **std**(标准) |
| 数据有大离群点、要鲁棒性 | **MAD** |
| 金融"风险"(惩罚大波动) | **std**(方差本身就是风险定义) |
| 房价中位数附近的散布 | MAD(尤其是 **Median Absolute Deviation**) |

→ MAD 也活得好好的, 只是不如 std 通用。

---

## 一段类比

> **MAD 像"普通人均距离":每个人离中心多远, 加起来除以人数。直觉好懂。**
>
> **std 像"物理学家的距离":每个人离中心的距离先平方, 平均后再开方。**
> **它在数学上像势能(W = ½kx²)、动能(KE = ½mv²)、电功率(P = V²/R)那样自然。**
>
> 物理世界里很多"能量"和"代价"都是平方的, 所以选用平方衡量"分散"在数学上、几何上、统计上同时是最优雅的。

---

## 一句话总结

> **标准差用"平方-平均-开方"是历史选择 + 数学必然**:
>
> - **历史**:Gauss 从天文误差推导正态分布时, 平方天然浮现
> - **数学**:可导(微积分友好)、可加(独立变量方差相加)、欧氏距离(几何友好)、正态分布的天然参数
> - **实用**:开方让单位回到和原数据一致, 方便理解
>
> MAD 简单但失去这些性质, 所以输给了 std。
