# 三角函数在金融里的应用例子


三角函数在金融中不像在物理、工程里那样直接出现，但它在一些金融模型和数据分析中仍然有重要应用，尤其是在**周期性分析、信号处理、量化交易**领域。

## 1. 分析市场周期（最常见）

金融市场经常存在周期现象：

* 日内周期（开盘、午盘、收盘）
* 周周期（星期一效应）
* 月周期（月末调仓）
* 季度周期（财报季）

量化研究员会用正弦波来拟合周期：

```math
P(t)=A\sin(\omega t+\phi)
```

其中：

* (A)：振幅（波动幅度）
* ($\omega$)：频率
* ($\phi$)：相位
* ($t$)：时间

例如：

```
股价
 ^
 |      /\        /\
 |     /  \      /  \
 |----/----\----/----\----> 时间
```

如果发现某个资产每 20 天左右出现一次规律波动，可以用三角函数描述。

---

## 2. 傅里叶变换（Fourier Transform）

这是三角函数在金融里最重要的应用之一。

傅里叶变换的核心思想：

> 任何复杂波动都可以拆成很多不同频率的正弦波和余弦波。

例如股价：

```
真实价格曲线

      /\__
 __/\_/   \___/\_
```

可以分解为：

```math
f(t)
=
a_1\sin(\omega_1 t)
+
a_2\sin(\omega_2 t)
+
a_3\sin(\omega_3 t)
+\cdots
```

这样可以分析：

* 市场主要周期
* 高频噪声
* 长期趋势

量化基金经常使用频谱分析：

* 高频交易（HFT）
* 趋势检测
* 市场微结构研究

都可能涉及傅里叶工具。

---

## 3. 时间特征编码（Machine Learning）

假设训练一个模型预测交易量。

直接使用：

```
小时:
0,1,2,...,23
```

有个问题：

```
23 点
↓
0 点
```

实际上相邻，但数字差了 23。

于是用三角函数编码：

```math
x_1=\sin\left(\frac{2\pi h}{24}\right)
```

```math
x_2=\cos\left(\frac{2\pi h}{24}\right)
```

这样：

* 23点和0点距离很近
* 保留周期特征

这是时间序列建模中非常常见的技巧。

例如：

* 交易量预测
* 订单流预测
* 做市策略特征工程

都会出现。

---

## 4. 高频交易中的信号滤波

订单簿数据非常嘈杂：

```
价格

101.2
101.1
101.3
101.0
101.4
101.2
...
```

很多变化只是噪声。

可以用傅里叶分析：

* 去除高频成分
* 保留低频趋势

本质上仍然是利用大量三角函数：

```math
\sin(\omega t)
```

```math
\cos(\omega t)
```

进行信号分解。

## 5. 期权定价中的应用

对于经典的 Black–Scholes 模型，公式里没有三角函数。

但是现代计算中会用到：

* 特征函数（Characteristic Function）
* 傅里叶变换定价

例如：

* Heston 波动率模型
* Carr–Madan 定价方法

其核心积分形式包含：

```math
e^{iu x}
```

根据 Euler 公式：

```math
e^{ix}
=
\cos x
+
i\sin x
```

所以底层仍然依赖三角函数。

这是量化衍生品领域的重要工具。

## 6. 资产相关性的几何解释

假设两个收益率向量：

```math
X=(x_1,x_2,\ldots,x_n)
```

```math
Y=(y_1,y_2,\ldots,y_n)
```

相关系数可以写成：

```math
\rho
=
\cos\theta
```

其中 (\theta) 是两个向量之间的夹角。

因此：

* (\theta=0^\circ)

```math
\rho=1
```

完全正相关。

* (\theta=90^\circ)

```math
\rho=0
```

不相关。

* (\theta=180^\circ)

```math
\rho=-1
```

完全负相关。

这在：

* 因子模型
* PCA
* 机器学习特征分析

里经常出现。

## 如果你做量化交易

结合你之前提到的 **Market Making/HFT** 学习方向，真正值得重点掌握的三角函数应用主要是：

1. **复数与欧拉公式**

```math
e^{ix}=\cos x+i\sin x
```

2. **傅里叶变换**

```math
f(t)
\leftrightarrow
F(\omega)
```

3. **频谱分析**

研究价格中的周期成分。

4. **时间周期特征编码**

```math
(\sin,\cos)
```

编码小时、星期、月份。

实际上，很多量化工程师很少直接计算 (\sin 30^\circ) 之类的问题，但会经常接触：

> 三角函数 → 复数 → 欧拉公式 → 傅里叶分析 → 信号处理 → 量化交易

这条知识链。对于现代量化金融而言，傅里叶分析的重要性远远高于传统几何意义上的三角形计算。
