# 上面我要求解释何为二维旋转矩阵， 但是你是基于和角公式来说明。能否不利用和角公式来解释二维旋转矩阵


完全可以，而且事实上这才是更符合逻辑顺序的讲法。

你发现了一个常见教材里的“循环解释”：

1. 用和角公式推导旋转矩阵
2. 再用旋转矩阵证明和角公式

这当然不是真正的推导链。

更合理的顺序应该是：

> 几何旋转 → 旋转矩阵 → 和角公式

而不是反过来。

---

## 从零开始：什么是旋转矩阵？

先忘掉 sin、cos、和角公式。

假设有一个线性变换 (R)：

它把平面上的所有点旋转 (\theta) 度。

例如：

```math
(1,0)
\rightarrow
(\text{某个新坐标})
```

```math
(0,1)
\rightarrow
(\text{某个新坐标})
```

---

## 线性代数的重要事实

任何二维线性变换都可以写成矩阵：

```math
A=
\begin{bmatrix}
a & b\\
c & d
\end{bmatrix}
```

而矩阵的两列就是：

* 第一列 = ((1,0)) 变换后的结果
* 第二列 = ((0,1)) 变换后的结果

因此只要知道：

```math
R(1,0)
```

和

```math
R(0,1)
```

整个矩阵就确定了。

---

## 观察单位向量

x轴单位向量：

```math
e_1=(1,0)
```

旋转 (\theta) 后：

长度不变，方向变成 (\theta)。

因此新坐标定义为：

```math
(\cos\theta,\sin\theta)
```

这里并没有用和角公式。

只是把 cos 和 sin 当成单位圆上的坐标定义。

即：

```math
R(e_1)
=
(\cos\theta,\sin\theta)
```

---

## 再看 y轴单位向量

```math
e_2=(0,1)
```

原来比 x 轴多 (90^\circ)。

旋转后：

方向变成：

```math
90^\circ+\theta
```

但我们暂时不需要和角公式。

直接从单位圆观察：

当角度是 (\theta) 时：

```math
(\cos\theta,\sin\theta)
```

那么再往前转 (90^\circ)：

x坐标会变成：

```math
-\sin\theta
```

y坐标会变成：

```math
\cos\theta
```

例如：

```math
(1,0)
\rightarrow
(0,1)
```

```math
(0,1)
\rightarrow
(-1,0)
```

`这是单位圆的纯几何事实。`

所以：

```math
R(e_2)
=
(-\sin\theta,\cos\theta)
```

---

## 矩阵立刻出现

第一列：

```math
\begin{bmatrix}
\cos\theta\\
\sin\theta
\end{bmatrix}
```

第二列：

```math
\begin{bmatrix}
-\sin\theta\\
\cos\theta
\end{bmatrix}
```

因此：

```math
R(\theta)
=
\begin{bmatrix}
\cos\theta & -\sin\theta\\
\sin\theta & \cos\theta
\end{bmatrix}
```


整个过程没有使用和角公式。

---

## 更深一层：甚至不用 sin 和 cos

还可以这样推。

假设旋转矩阵是：

```math
R=
\begin{bmatrix}
a & b\\
c & d
\end{bmatrix}
```

旋转必须满足：

### 长度保持

```math
R^TR=I
```

即：

```math
a^2+c^2=1
```

```math
b^2+d^2=1
```

```math
ab+cd=0
```

---

### 保持方向

要求：

```math
\det(R)=1
```

解这组方程会得到：

```math
R=
\begin{bmatrix}
a & -c\\
c & a
\end{bmatrix}
```

并且

```math
a^2+c^2=1
```

于是可以把：

```math
a=\cos\theta
```

```math
c=\sin\theta
```

作为参数化。

得到：

```math
R=
\begin{bmatrix}
\cos\theta & -\sin\theta\\
\sin\theta & \cos\theta
\end{bmatrix}
```

这里甚至不是从三角函数出发。

而是：

> 所有保持长度和角度的二维线性变换，必然长成这个样子。

然后我们才把参数 (a,c) 命名为：

```math
a=\cos\theta,\quad c=\sin\theta
```

---

这也是现代线性代数和李群理论的观点：

**旋转矩阵不是由三角函数产生的；恰恰相反，三角函数是描述旋转矩阵最方便的坐标系统。**

从这个角度看：

```math
\sin(a+b)
```

和

```math
\cos(a+b)
```

其实是旋转矩阵满足

```math
R(a+b)=R(a)R(b)
```

后自然推导出来的结果，而不是前提。
