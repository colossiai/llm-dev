# 为什么在代数运算时会包含三角函数， 三角函数只是一个比率？

这是一个很好的问题。很多人刚学三角函数时，会觉得：

> 三角函数不就是直角三角形边长的比率吗？为什么后来在代数、微积分、物理里面到处都是三角函数？

原因在于：**三角函数本质上不是“边长比率”，而是一类特殊的函数。边长比率只是它最早的定义方式。**

---

## 1. 最初：三角函数确实是边长比率

例如直角三角形：

```math
\sin\theta=\frac{\text{对边}}{\text{斜边}}
```

```math
\cos\theta=\frac{\text{邻边}}{\text{斜边}}
```

```math
\tan\theta=\frac{\text{对边}}{\text{邻边}}
```

古代数学家主要用它解决：

* 测量高度
* 测量距离
* 天文计算

例如：

已知

* 仰角 ($30^\circ$)
* 到塔底距离 (100m)

则

```math
\tan 30^\circ=\frac{h}{100}
```

从而求出塔高。

---

## 2. 后来发现：三角函数可以脱离三角形

把点放到单位圆上：

```math
x^2+y^2=1
```

对于角度 (\theta)：

```math
(\cos\theta,\sin\theta)
```

定义：

```math
\cos\theta=x
```

```math
\sin\theta=y
```

此时：

* 不需要直角三角形
* 不需要边长

三角函数变成：

```math
\sin:\mathbb R\to```math-1,1```
```

```math
\cos:\mathbb R\to```math-1,1```
```

就是普通函数。

---

## 3. 为什么代数里面会出现？

因为它们满足很多漂亮的代数关系。

例如：

```math
\sin^2x+\cos^2x=1
```

```math
\sin(a+b)
=
\sin a\cos b+\cos a\sin b
```

```math
\cos(a+b)
=
\cos a\cos b-\sin a\sin b
```

这些都是代数恒等式。

因此可以像操作多项式一样操作三角函数。

例如：

```math
\sin(2x)
=
2\sin x\cos x
```

这已经完全是代数变换了。

---

## 4. 更深层原因：旋转

三角函数实际上描述的是：

> **二维平面上的旋转**

旋转角度 (\theta)：

```math
\begin{bmatrix}
x'\
y'
\end{bmatrix}
=
\begin{bmatrix}
\cos\theta & -\sin\theta\\
\sin\theta & \cos\theta
\end{bmatrix}
\begin{bmatrix}
x\
y
\end{bmatrix}
```

这里：

* ($\sin$)
* ($\cos$)

自然出现在旋转矩阵里。

所以：

* 几何
* 线性代数
* 机器人
* 图形学
* 飞机导航

都会出现三角函数。

---

## 5. 为什么微积分特别喜欢三角函数？

因为它们有特殊性质：

```math
\frac{d}{dx}\sin x=\cos x
```

```math
\frac{d}{dx}\cos x=-\sin x
```

求导以后还是自己家族成员。

类似：

```math
e^x
```

求导后还是：

```math
e^x
```

这种性质非常罕见。

因此大量自然现象都能写成三角函数。

---

## 6. 为什么物理里到处是三角函数？

因为自然界充满振动和周期运动。

例如弹簧：

```math
x(t)=A\cos(\omega t)
```

声波：

```math
A\sin(\omega t)
```

电磁波：

```math
E(t)=E_0\sin(\omega t)
```

交流电：

```math
V(t)=V_0\sin(\omega t)
```

只要系统满足

```math
x''=-kx
```

其解就一定是：

```math
\sin
```

和

```math
\cos
```

---

## 7. 从现代数学角度看

最本质的定义甚至不是边长比率。

利用无穷级数：

```math
\sin x
=
x-\frac{x^3}{3!}
+\frac{x^5}{5!}
-\cdots
```

```math
\cos x
=
1-\frac{x^2}{2!}
+\frac{x^4}{4!}
-\cdots
```

此时：

* 没有三角形
* 没有圆
* 没有几何

三角函数纯粹是一个代数对象。

然后可以证明：

这些函数恰好等于单位圆上的坐标。

---

## 最核心的一句话

“三角函数是边长比率”只是它的历史起点。

现代数学中，三角函数更准确地说是：

> **描述圆周运动、旋转和周期现象的一类特殊函数。**

因为它们满足大量优美的代数恒等式、微分性质和几何性质，所以会自然地出现在代数、线性代数、微积分、物理和工程中。
