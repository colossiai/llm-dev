# 二维空间如何表达点的移动， 用线性变换？ 还是有其他更优的方法


这是一个非常好的问题。答案取决于你说的"移动（movement）"到底包含什么。

* **如果只是旋转、缩放、镜像** → 线性变换就够了。
* **如果包含平移（Translation）** → 单纯线性变换不够，需要仿射变换（Affine Transformation）。
* **如果描述的是随时间运动** → 通常会用参数方程、微分方程或运动模型。

下面分别解释。

---

# 1. 什么叫线性变换？

二维点

```math
P=\begin{bmatrix}
x\\
y
\end{bmatrix}
```

经过一个矩阵

```math
A=
\begin{bmatrix}
a&b\
c&d
\end{bmatrix}
```

得到

```math
P'=AP
```

例如

旋转

```math
\begin{bmatrix}
0&-1\\
1&0
\end{bmatrix}
```

把

```math
(2,1)
```

变成

```math
(-1,2)
```

整个平面所有点都会一起变化。

---

线性变换能够表示

✅ 旋转

✅ 缩放

✅ 镜像

✅ 剪切（Shear）

例如

```
原来

   ●

旋转90°

●
```

---

# 2. 为什么线性变换不能表示移动（Translation）

假设

点

```math
(1,2)
```

移动

```math
(+3,+5)
```

得到

```math
(4,7)
```

有没有矩阵

```math
A
```

满足

```math
AP=
P+
\begin{bmatrix}
3\\
5
\end{bmatrix}
```

答案：

**没有。**

原因很简单：

线性变换必须满足

```math
A0=0
```

但是平移以后

```math
0
\rightarrow
(3,5)
```

违反了线性定义。

所以

> **平移不是线性变换。**

---

# 3. 那怎么办？——仿射变换（Affine Transformation）

真正二维图形几乎全部使用

**仿射变换**

公式

```math
P'
==

AP+b
```

其中

矩阵负责

* 旋转
* 缩放
* 剪切

向量

```math
b=
\begin{bmatrix}
t_x\
t_y
\end{bmatrix}
```

负责平移。

例如

```math
A=
I
=

\begin{bmatrix}
1&0\\
0&1
\end{bmatrix}
```

```math
b=
\begin{bmatrix}
5\\
2
\end{bmatrix}
```

那么

```math
(1,3)
\rightarrow
(6,5)
```

就是纯移动。

---

所以二维图形通常写成

```math
P'
==

AP+b
```

而不是

```math
P'=AP
```

---

# 4. 为什么计算机图形学不用这个公式？

因为

```
AP+b
```

不好连续相乘。

例如

先旋转

再平移

再缩放

写起来变成

```
A3(A2(A1P+b1)+b2)+b3
```

越来越复杂。

于是计算机图形学引入了

## 齐次坐标（Homogeneous Coordinates）

把二维点

```
(x,y)
```

变成

```
(x,y,1)
```

于是

所有操作统一写成矩阵。

例如

平移

```math
\begin{bmatrix}
1&0&t_x\\
0&1&t_y\\
0&0&1
\end{bmatrix}
```

乘

```math
\begin{bmatrix}
x\\
y\\
1
\end{bmatrix}
```

得到

```math
\begin{bmatrix}
x+t_x\\
y+t_y\\
1
\end{bmatrix}
```

于是

旋转

缩放

移动

全部都是矩阵乘法。

所以

OpenGL

DirectX

CAD

机器人

SLAM

游戏引擎

全部使用

**3×3齐次矩阵。**

---

# 5. 如果是真正"运动"呢？

如果点在连续运动

例如

一只鸟飞

一个汽车开

那通常不用变换矩阵。

而是

位置变成时间函数。

例如

```math
P(t)
=
(x(t),y(t))
```

例如

匀速

```math
x=x_0+vt
```

```math
y=y_0
```

画出来就是

```
●→→→→
```

---

如果有加速度

```math
x=x_0+v_xt+\frac12at^2
```

这就是物理里的运动模型。

---

# 6. 更复杂的运动

机器人、游戏、自动驾驶通常写成状态方程

```math
\mathbf{x}_{t+1}
=
A\mathbf{x}_t+B\mathbf{u}
```

状态包括

```
位置

速度

角度

角速度

加速度
```

例如

```
x
y
vx
vy
```

全部组成一个向量。

这就是状态空间模型（State-space Model），也是控制理论、机器人和滤波算法（如卡尔曼滤波）中的标准表示方法。

---

# 总结：不同需求对应不同表示方法

| 需求       | 数学表达      | 是否线性            |
| -------- | --------- | --------------- |
| 旋转       | (P'=AP)   | ✅               |
| 缩放       | (P'=AP)   | ✅               |
| 镜像       | (P'=AP)   | ✅               |
| 剪切       | (P'=AP)   | ✅               |
| 平移       | (P'=AP+b) | ❌（仿射）           |
| 图形学所有变换  | 3×3 齐次矩阵  | ✅（在线性代数框架下统一表示） |
| 连续运动     | (P(t))    | 不一定             |
| 物理运动     | 微分方程      | 不一定             |
| 自动驾驶/机器人 | 状态空间模型    | 常采用线性或局部线性模型    |

**可以把它们理解为一个层次结构：**

```text
二维点 (x, y)
        │
        ▼
线性变换：P' = A·P
（旋转、缩放、镜像、剪切）
        │
        ▼
仿射变换：P' = A·P + b
（加入平移，是二维图形学最常用的模型）
        │
        ▼
齐次坐标：3×3 矩阵
（把所有仿射变换统一为矩阵乘法，便于组合）
        │
        ▼
时间维度：P(t)
（描述点如何随时间运动）
        │
        ▼
动力学模型：ẋ = f(x, u)
（用于机器人、物理仿真、自动驾驶等真实运动系统）
```

因此，如果你的目标是**表达二维空间中的点如何移动**，最常用且最实用的方法是**仿射变换**；如果需要方便地组合多个变换，则使用**齐次坐标**；如果要描述**随时间演化的运动轨迹**，则应使用**参数方程或动力学模型**。
