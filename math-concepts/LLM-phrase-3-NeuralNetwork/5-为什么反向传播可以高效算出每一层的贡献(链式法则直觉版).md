# 为什么反向传播可以高效算出每一层的贡献？（链式法则直觉版）


这是理解神经网络最关键的几个概念之一。

很多初学者第一次看到反向传播（Backpropagation）都会想：

> 一个神经网络可能有几百万个参数，
> 难道要一个个试试看哪个参数重要吗？

如果真的这么做，训练一个模型可能要几千年。

反向传播厉害的地方就在于：

> **只需要一次前向传播 + 一次反向传播，就能同时算出所有参数对误差的贡献。**

秘诀来自微积分中的 **链式法则（Chain Rule）**。

---

# 1. 先看一个简单网络

假设网络只有三层：

```text
x
↓
w1
↓
h
↓
w2
↓
y
↓
Loss
```

数学上：

```math
h = xw_1
\\
y = hw_2
\\
Loss = (y-target)^2
```

现在训练的目标：

```text
Loss越小越好
```

因此我们要知道：

```text
w1 应该增加还是减少？
w2 应该增加还是减少？
```

---

# 2. 最笨的方法

假设：

```text
w1 = 1.5
```

你可以试：

```text
1.5001
1.5002
1.5003
...
```

看看 Loss 有没有变小。

这叫：

```text
Numerical Gradient
数值求导
```

但是：

```text
100M 参数
```

意味着：

```text
100M 次实验
```

根本不可行。

---

# 3. 链式法则在干什么

先看：

```text
w1
↓
h
↓
y
↓
Loss
```

Loss受到w1影响：

```text
w1改变
→ h改变
→ y改变
→ Loss改变
```

因此：

```math
\frac{\partial Loss}{\partial w_1}
```

可以拆开：

```math
\frac{\partial Loss}{\partial w_1}
=
\frac{\partial Loss}{\partial y}
\times
\frac{\partial y}{\partial h}
\times
\frac{\partial h}{\partial w_1}
```

这就是链式法则。

直觉上：

```text
最终损失对w1有多敏感

=

损失对y有多敏感
×
y对h有多敏感
×
h对w1有多敏感
```

---

# 4. 为什么叫“误差倒流”

训练时先前向计算：

```text
x
↓
h
↓
y
↓
Loss
```

得到：

```text
Loss = 10
```

然后从Loss开始往回看：

```text
Loss
↑
y
↑
h
↑
w1
```

先计算：

```math
\frac{\partial Loss}{\partial y}
```

然后利用它计算：

```math
\frac{\partial Loss}{\partial h}
```

再利用结果计算：

```math
\frac{\partial Loss}{\partial w_1}
```

所以梯度像水流一样：

```text
Loss
↑
↑
↑
输出层
↑
隐藏层
↑
输入层
```

一路往回传。

因此叫：

```text
Back Propagation
反向传播
```

---

# 5. 为什么特别高效

想象：

```text
A → B → C → D → Loss
```

如果分别计算：

```text
A贡献
B贡献
C贡献
D贡献
```

会重复大量计算。

例如：

```math
\frac{\partial Loss}{\partial D}
```

算过一次后：

```math
\frac{\partial Loss}{\partial C}
```

还会用到。

反向传播的思想：

```text
算一次
缓存下来
后面直接复用
```

例如：

```math
g_D
=
\frac{\partial Loss}{\partial D}
```

已经算出来了。

那么：

```math
g_C
=
g_D
\times
\frac{\partial D}{\partial C}
```

即可。

不用重新从Loss开始算。

---

# 6. 动态规划视角

其实反向传播非常像：

```text
动态规划（DP）
```

DP思想：

```text
子问题只算一次
结果复用
```

反向传播：

```text
某层梯度只算一次
后面全部复用
```

所以复杂度大幅下降。

---

# 7. 一个数字例子

假设：

```text
x = 2
w1 = 3
w2 = 4
target = 10
```

前向传播：

```math
h = 2×3 = 6
```

```math
y = 6×4 = 24
```

```math
Loss=(24-10)^2=196
```

---

先算输出误差：

```math
\frac{\partial Loss}{\partial y}
=
2(24-10)
=
28
```

然后传播到w2：

```math
\frac{\partial y}{\partial w_2}
=
h
=
6
```

因此：

```math
\frac{\partial Loss}{\partial w_2}
=
28×6
=
168
```

---

传播到w1：

```math
\frac{\partial y}{\partial h}
=
w_2
=
4
```

```math
\frac{\partial h}{\partial w_1}
=
x
=
2
```

因此：

```math
\frac{\partial Loss}{\partial w_1}
=
28×4×2
=
224
```

这里的

```text
28
```

只算了一次。

后面一路复用。

这就是反向传播高效的核心。

---

# 最重要的直觉

反向传播本质上是在回答：

> **如果某个参数稍微改变一点点，最终Loss会变化多少？**

而链式法则告诉我们：

> **不用从头计算每个参数的影响，只需要把误差信号从输出层一层层传回来。**

所以：

```text
前向传播：
数据往前流

x → hidden → output
```

```text
反向传播：
梯度往后流

Loss → output → hidden → input
```

整个神经网络训练，本质上就是不断重复：

```text
前向传播
→ 计算Loss
→ 反向传播
→ 梯度下降更新参数
→ 再前向传播
```

这四步循环几十亿次，最终学出像 GPT 这样的模型。
