# 给一个简单的多参数的具体例子，跑几个循环， 说明参数是如何被反向传播流程改变的



下面我们升级到一个**真正有多个参数的神经网络**。

为了看清楚反向传播如何给不同参数“分配责任”，我们用一个只有 **2个权重 + 1个偏置** 的模型：

```text
输入 x

      w
x ───────►
           +
           b
           ↓
        y_pred
```

公式：

```math
y_{pred}=w_1x_1+w_2x_2+b
```

目标数据：

```text
x1 = 1
x2 = 2

真实值 y = 10
```

初始参数：

```text
w1 = 1
w2 = 1
b  = 0
```

学习率：

```text
lr = 0.1
```

Loss：

```text
Loss = (y_pred - y)^2
```

---

# 第0轮（初始化）

## 前向传播

```text
y_pred

= 1×1 + 1×2 + 0

= 3
```

---

## Loss

```text
(3 - 10)^2

= 49
```

误差：

```text
-7
```

---

# 反向传播

先求：

```text
dLoss/dy_pred
```

因为：

```text
Loss=(y_pred-y)^2
```

所以：

```text
= 2(y_pred-y)

= 2(3-10)

= -14
```

---

## 求 w1 的梯度

因为：

```text
y_pred = w1x1 + w2x2 + b
```

所以：

```text
dy_pred/dw1 = x1 = 1
```

链式法则：

```text
dLoss/dw1

=
dLoss/dy_pred
×
dy_pred/dw1

=
(-14) × 1

=
-14
```

---

## 求 w2 的梯度

```text
dy_pred/dw2 = x2 = 2
```

因此：

```text
dLoss/dw2

=
(-14) × 2

=
-28
```

---

## 求 b 的梯度

```text
dy_pred/db = 1
```

因此：

```text
dLoss/db

=
(-14) × 1

=
-14
```

---

# 参数更新

公式：

```text
param = param - lr × gradient
```

---

更新 w1：

```text
1 - 0.1(-14)

=
2.4
```

更新 w2：

```text
1 - 0.1(-28)

=
3.8
```

更新 b：

```text
0 - 0.1(-14)

=
1.4
```

---

得到：

```text
w1 = 2.4
w2 = 3.8
b  = 1.4
```

---

# 观察一下

注意：

```text
|gradient(w2)|

=

28
```

比：

```text
|gradient(w1)|

=

14
```

大一倍。

为什么？

因为：

```text
x2 = 2
x1 = 1
```

模型认为：

```text
w2 对输出影响更大
```

因此：

```text
w2 改得更多
```

这就是：

```text
责任分配
```

的含义。

# 这就是反向传播在干什么

假设当前预测：

```text
预测 = 3
真实 = 10
```

网络发现：

```text
差了 7
```

然后问：

```text
是谁造成的？
```

反向传播回答：

```text
w1 贡献了多少误差？
w2 贡献了多少误差？
b 贡献了多少误差？
```

通过梯度：

```text
dLoss/dw1
dLoss/dw2
dLoss/db
```

把责任量化出来。

然后：

```text
责任大
→ 改得多

责任小
→ 改得少
```

在大型神经网络里（例如 Transformer）：

```text
w1,w2,b
```

会变成：

```text
10亿+
参数
```

但做的事情完全一样：

```text
前向传播
↓
得到Loss
↓
反向传播
↓
计算每个参数的责任(梯度)
↓
更新参数
↓
Loss变小
```

这就是深度学习训练的核心循环。
