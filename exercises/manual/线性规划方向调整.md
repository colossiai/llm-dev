# 线性回归中 w 和 b 的方向调整

## 问题

在 `exercises/manual/manual_lin_regre.py` 手动计算线性回归里面，没有判断 w 和 b 应该往哪个方向调整？是因为 x, y 是线性关系？

## 回答

不是因为线性关系，而是**梯度本身就带方向（正负号）**，所以不需要再写 if/else 判断。

看 `manual_lin_regre.py:25-26`：

```python
dw += 2 * error * x      # error = y_hat - y
db += 2 * error
```

`error = y_hat - y` 是**有符号**的：

- 如果 `y_hat > y`（预测偏大）→ `error > 0` → `dw > 0`（假设 x>0）→ `w -= lr * dw` 让 w **变小**
- 如果 `y_hat < y`（预测偏小）→ `error < 0` → `dw < 0` → `w -= lr * dw` 让 w **变大**

`b` 同理。

## 关键点

梯度下降的更新公式 `w -= lr * dw` 里，**负号 + dw 的符号** 已经把"该往哪走"算清楚了：

| dw 的符号 | 含义 | 更新后 w |
|---|---|---|
| dw > 0 | loss 随 w 增大而增大 | w 变小 |
| dw < 0 | loss 随 w 增大而减小 | w 变大 |

这是**所有可微函数**通用的规律，跟 x、y 是不是线性关系无关。哪怕换成神经网络（非线性），更新公式还是 `w -= lr * dw`，不需要 if 判断方向。

## 类比

想象你蒙着眼站在山坡上，想下山。你不需要"先判断哪边低再迈步"，只要感受脚下**坡度的方向**（梯度），然后**朝反方向**走一步即可。`-=` 里的负号就是"朝反方向"。
