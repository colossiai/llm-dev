# 01_attention_scratch.py 详细流程图解

> 配套脚本:`exercises/transformer/01_attention_scratch.py`
> 公式:`Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k) · V`

## 全景:一条数据流穿过整个脚本

```
   tokens (6个词)
 ["The","cat","sat","on","the","mat"]
        │
        │  ① 查 embedding 表 (dict 模拟 nn.Embedding)
        │     同一个词 → 同一个向量 (The/the 相同)
        ▼
   X  (6, 8)            ← 6个token, 每个8维 embedding
        │
        │  ② 三个投影矩阵 W_Q / W_K / W_V  (8, 8)
        │     同一个 X, 投影出三种"视角"
        ├───────────────┬───────────────┐
        ▼               ▼               ▼
   Q (6,8)         K (6,8)         V (6,8)
  "我想找什么"     "我能提供什么"   "我真实内容"
        │               │               │
        └──────┬────────┘               │
               │ ③ scores = Q·Kᵀ        │
               ▼   (6,6) 相关度打分      │
        scores (6,6)                    │
               │ ÷√d_k 缩放 → softmax    │
               ▼                        │
         attn (6,6)  ← 每行和=1 的权重    │
               │                        │
               └──────────┬─────────────┘
                          │ ④ out = attn·V
                          ▼
                     out (6,8)  ← 每个token的新表示
```

一句话:**`X →(投影)→ Q,K,V →(打分+归一化)→ attn →(加权V)→ out`**,shape 走向是 `(6,8) → (6,8)×3 → (6,6) → (6,8)`。

---

## 第①步:查表得到 X (脚本 88–107 行)

模拟 `nn.Embedding`:把词转成向量。关键点是**重复词拿到相同向量**。

```
  词表 vocab = [cat, mat, on, sat, the]   (5个唯一词)
  embedding_table = { 词 : 随机8维向量 }   ← 这就是"embedding 表"

  tokens:  The   cat   sat   on    the   mat
            │     │     │     │     │     │   (都先 .lower())
            ▼     ▼     ▼     ▼     ▼     ▼
  X[0]=v_the  v_cat v_sat v_on  v_the v_mat
            └───────────────────┘
              X[0] == X[4]  ✓  ("The" 和 "the" 同向量)
```

| 概念 | 真实 LLM | 本脚本 |
|------|---------|--------|
| 查表机制 | `nn.Embedding(vocab, d_model)` | Python `dict` |
| 向量来源 | 训练学出来 | `np.random.randn` 随机 |
| 同词同向量 | ✓ | ✓ (靠 `.lower()` 归一) |

> 💡 这里 X 只是"词义"向量,**还没有位置信息**——所以这个 attention 此刻分不清词序(那是后面 positional encoding 的事)。

---

## 第②步:投影出 Q / K / V (113–124 行)

同一个 X 乘三个不同矩阵,得到三个不同视角。这是 attention 需要三个矩阵的核心。

```
        W_Q(8,8)            W_K(8,8)            W_V(8,8)
          │                   │                   │
  X(6,8) ─┤                   │                   │
          ▼                   ▼                   ▼
       Q = X@W_Q           K = X@W_K           V = X@W_V
        (6,8)               (6,8)               (6,8)
```

矩阵乘法对齐(逐 token 独立投影):

```
   X      @   W_Q   =    Q
 (6, 8)     (8, 8)     (6, 8)
        内维8对齐↑
```

| | 角色 | 类比 | 用途 |
|---|------|------|------|
| **Q** Query | 我想找什么 | 提问 | 拿去和别人 K 比 |
| **K** Key | 我能提供什么 | 标签/索引 | 被别人 Q 比 |
| **V** Value | 我真实的内容 | 内容 | 最终被取走的信息 |

> 注意:因为 X[0]==X[4],所以投影后 Q[0]==Q[4]、K[0]==K[4]、V[0]==V[4] 也成立(线性变换保持相等)。

---

## 第③步:打分 → 缩放 → softmax (54–70 行)

这是 attention 的"心脏"。

**3a. `scores = Q @ K.T`** —— 每个 token 对每个 token 的相关度

```
    Q(6,8)  @  Kᵀ(8,6)   =   scores(6,6)

   scores[i,j] = Q[i]·K[j]  = "token i 对 token j 的关注分数"

         key→  The  cat  sat  on  the  mat
   query↓  ┌────────────────────────────┐
    The    │  ·    ·    ·   ·    ·    ·  │  ← 第0行: The 对所有词的分数
    cat    │  ·    ·    ·   ·    ·    ·  │
    sat    │  ·    ·    ·   ·    ·    ·  │
    on     │  ·    ·    ·   ·    ·    ·  │
    the    │  ·    ·    ·   ·    ·    ·  │
    mat    │  ·    ·    ·   ·    ·    ·  │
           └────────────────────────────┘
```

**3b. `÷ √d_k`** —— 缩放,控制方差

```
   d_k=8,  √d_k ≈ 2.83
   scores ← scores / 2.83     (把数值压小, 防止 softmax 过度尖锐)
```

> 为什么:d_k 越大,Q·K 累加项越多→方差越大→softmax 几乎只关注一个词(梯度消失,训练不稳)。除 √d_k 把方差拉回 ~1。

**3c. `softmax(axis=-1)`** —— 按行归一成概率

```
  对每一行单独做 softmax:
     attn[i,:] = exp(scores[i,:]) / Σ exp(scores[i,:])

  原始打分                       softmax后 (每行和=1)
  [ 2.1  0.3  1.5 ...]   ──→   [0.45 0.08 0.22 ...]  Σ=1.000
                          越大的分数 → 越大的权重
```

softmax 里先减 `max`(49行)纯粹是**防 `exp` 溢出**的数值技巧,不改变结果。

---

## 第④步:加权求和 V → 输出 (72–75 行)

```
   attn(6,6)  @  V(6,8)  =  out(6,8)

   out[i] = Σⱼ attn[i,j] · V[j]
          = "token i 按注意力权重, 把大家的 V 混合成自己的新表示"

   例: out[cat] = 0.45·V[The] + 0.08·V[cat] + 0.22·V[sat] + ...
                  └─ 关注谁多, 谁的内容就占比大 ─┘
```

**为什么形状又变回 (6,8)?** 输入 6 个 token、输出还是 6 个 token,每个被"上下文增强"过——这样 attention 层才能堆叠多层。

## 一句话总结

整个脚本就是把公式 `Attention(Q,K,V)=softmax(QKᵀ/√d_k)·V` 用 numpy 拆成**四步看 shape**:
**查表得 X(6,8) → 三投影得 Q/K/V → QKᵀ 打分+softmax 得权重矩阵(6,6) → 权重乘 V 得输出(6,8)**,核心直觉是「**每个词用 Q 去问、用别人的 K 算关注度、再把别人的 V 按关注度加权混合成自己的新表示**」。
