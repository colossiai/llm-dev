  为什么存的不只是权重

  torch.save 里我打包了三样东西，缺一不可：

  ┌─────────────┬─────────────────────────────────────────────────────────┬──────────────────────────────────────────────────┐
  │    字段     │                          内容                           │                    不存的后果                    │
  ├─────────────┼─────────────────────────────────────────────────────────┼──────────────────────────────────────────────────┤
  │ model_state │ model.state_dict()，学到的全部权重                      │ 没它就什么都没保存                               │
  ├─────────────┼─────────────────────────────────────────────────────────┼──────────────────────────────────────────────────┤
  │ config      │ vocab_size / d_model / n_layers / n_heads / max_seq_len │ 没它没法重建模型骨架，load_state_dict 形状对不上 │
  ├─────────────┼─────────────────────────────────────────────────────────┼──────────────────────────────────────────────────┤
  │ vocab       │ char_to_id / id_to_char                                 │ 没它加载后无法 encode/decode，模型成了"哑巴"     │
  └─────────────┴─────────────────────────────────────────────────────────┴──────────────────────────────────────────────────┘

  （外加 final_loss 做个记录）

  重新加载（脚本运行时也会打印这段提示）

  ckpt = torch.load("checkpoints/06_minigpt.pt")
  model = MiniGPT(**ckpt["config"])
  model.load_state_dict(ckpt["model_state"])
  model.eval()
  # encode/decode 用 ckpt["vocab"] 里的两个映射

  ▎ 一句话：只 torch.save(model.state_dict()) 是不够的——重建模型需要 config，做推理需要 vocab，所以这里存的是一个自包含的 checkpoint 字典。
