# 04_transformer_block.py 详细流程图解

> 配套脚本:`exercises/transformer/04_transformer_block.py`
> 核心:把 03 的多头注意力**包装成一个完整的、可堆叠的 Transformer Block**,新增三个零件:**FFN、残差连接、LayerNorm**。

## 全景:一个 Block = 两个"Pre-Norm 子层"串联

```
   x (B,T,d)
    │
    ├──────────────────── 残差快捷线 ①
    ▼                                  │
  LayerNorm(ln1)                       │   子层1: 让token之间"交流"
    ▼                                  │
  Multi-Head Attention (03 整个)       │
    ▼                                  │
    +  ◄──────────────────────────────┘   x = x + attn(ln1(x))
    │
    ├──────────────────── 残差快捷线 ②
    ▼                                  │
  LayerNorm(ln2)                       │   子层2: 每个token自己"再加工"
    ▼                                  │
  FFN (Linear→GELU→Linear)             │
    ▼                                  │
    +  ◄──────────────────────────────┘   x = x + ffn(ln2(x))
    │
    ▼
   x' (B,T,d)   ← 形状不变, 可无限堆叠
```

代码就两行(128–133 行),和图严格对应:

```python
x = x + self.attn(self.ln1(x))   # 子层1
x = x + self.ffn (self.ln2(x))   # 子层2
```

| 零件 | 作用一句话 | 类比 |
|------|-----------|------|
| **MHA**(03) | token 之间交流上下文 | 开会讨论 |
| **FFN** | 每个 token 独立深加工 | 会后各自消化 |
| **残差** `x +` | 输出=输入+微调,不全盘替换 | 在原稿上批注 |
| **LayerNorm** | 把每个 token 向量归一,数值不炸 | 每步后校准音量 |

---

## 零件①:FFN —— 每个 token 自己加工 (95–111 行)

Attention 负责"token 间交流",FFN 负责"token 自己想想"。它是一个**先扩张 4 倍再压回**的两层 MLP:

```
  x (B,T,32)
    │ fc1: Linear(32 → 128)      ← 扩张 4 倍, 给非线性更大空间
    ▼
  hidden (B,T,128)
    │ GELU 激活                   ← 唯一的非线性来源
    ▼
    │ fc2: Linear(128 → 32)      ← 压回 d_model
    ▼
  out (B,T,32)
```

> "position-wise":同一个 MLP **逐 token 独立**作用,token 之间不交互(交互是 attention 干的)。GPT/BERT 用 GELU,现代 LLaMA 用 SiLU/SwiGLU。

---

## 零件②:残差连接 `x + ...` (130, 132 行)

不是 `x = f(x)`,而是 `x = x + f(x)`:

```
        x ──────────────┐ 快捷通道(identity)
        │               │
      f(x) 子层 ─────────┤
                        ▼
                   x + f(x)
```

| 好处 | 说明 |
|------|------|
| 梯度不消失 | `x+f(x)` 的导数含 `1`,反向传播有"高速路"直达底层 |
| 层可"摆烂" | 某层即使 `f(x)≈0`,信息仍能原样穿过 → 深层网络可训练 |

这就是能把 block 堆到 96 层(GPT-3)还训得动的关键。

---

## 零件③:LayerNorm —— 数值校准 (123–124 行)

对**每个 token 的向量**(最后一维 d)做标准化:减均值、除标准差、再缩放:

```
  对一个 token 的 32 维向量:
  x = [a, b, c, ... ]  ──► (x - mean) / std * γ + β
                            └ 拉成 均值≈0, 方差≈1, 再可学习微调 ┘
```

**Pre-Norm vs Post-Norm**(本篇用 Pre-Norm,GPT/LLaMA 同款):

| | 写法 | 特点 |
|---|------|------|
| Post-Norm(原论文2017) | `x = LN(x + f(x))` | 深层易不稳 |
| **Pre-Norm**(现代) | `x = x + f(LN(x))` | norm 在子层**内部**,残差路径干净,更稳 ✓ |

关键:Pre-Norm 里残差快捷线上**没有 LayerNorm**,梯度高速路完全畅通。

## 堆叠实验:6 层,看数值稳不稳 (169–195 行)

Block 输入输出同形 `(B,T,d)`,所以能用 `ModuleList` 无脑堆 N 层。脚本堆 6 层,逐层打印激活的 mean/std:

```
   层    | mean     | std      | range
  ─────────────────────────────────────
   输入  | ~0       | ~1       | [-4, +4]
   1     | ...      | ~1.x     |          ┐
   2     | ...      | ~1.x     |          │ std 始终被
   ...   |          |          |          │ LayerNorm 拉住,
   6     | ...      | ~1.x     |          ┘ 不爆炸/不消失
```

**核心观察:std 一直待在合理范围**——这就是 LayerNorm 在工作。没有它,深层网络数值会指数级失控。

---

## 参数量:一个 Block ≈ 12 d²

```
  MHA:  W_qkv(3d²) + W_o(d²)           = 4d²
  FFN:  fc1(d×4d) + fc2(4d×d)          = 8d²   (+少量bias)
  LN:   2×(γ+β) = 4d                    ≈ 0(可忽略)
  ──────────────────────────────────────────
  合计 ≈ 12 d²
```

> GPT-3:96 层 × d=12288 → 175B 参数,就是这个 block 堆出来的。

### GPT-3 的 175B 是怎么算出来的

核心就是上面的 `每层 ≈ 12 d²` 公式,乘层数再加 embedding。

GPT-3 175B 配置:`d_model = 12288`,`n_layers = 96`。

```
  d²          = 12288²        = 150,994,944        ≈ 1.51 亿
  每层 12d²    = 12 × 1.51e8   = 1,811,939,328      ≈ 18.1 亿/层
  × 96 层      = 18.1e8 × 96   = 173,946,175,488    ≈ 173.9 B
```

主体已经 173.9B,再补上两个 embedding 表:

```
  token embedding : vocab × d  = 50257 × 12288 = 617,558,016  ≈ 0.62 B
  position embed   : 2048 × d  =  2048 × 12288 =  25,165,824  ≈ 0.03 B
  ──────────────────────────────────────────────────────────────────
  总计 ≈ 173.9 + 0.62 + 0.03 ≈ 174.6 B  ≈ 175 B  ✓
```

占比:

```
   175B 参数构成
   ┌─────────────────────────────────────────────┐
   │ 96 层 Block  (每层 12d²=1.81B)        ~99.6% │ ████████████████
   │   ├ 注意力 4d² ──── 33%                       │
   │   └ FFN     8d² ──── 67%  (FFN 才是大头!)     │
   │ token embedding   50257×d            ~0.35%  │ ▏
   │ position embedding 2048×d            ~0.01%  │
   └─────────────────────────────────────────────┘
```

> 关键直觉:参数量随宽度 d **平方增长**、随层数 n **线性增长**;每层里 **FFN(8d²)比注意力(4d²)大一倍**,是真正的参数大户。

## 一句话总结

Transformer Block = **把 03 的多头注意力 + 一个 FFN,各自包上「Pre-Norm + 残差」两层皮**,数据流就是 `x = x + attn(LN(x))` 接 `x = x + ffn(LN(x))`;attention 让 token 互相交流、FFN 让每个 token 自我加工、残差给梯度高速路、LayerNorm 稳住数值;因为输入输出同形,它能像乐高一样堆 N 层(GPT-3 堆 96 层),这就是整个 GPT/LLaMA 的主体结构。
