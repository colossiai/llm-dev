# Mini LLM 简练理解 + 纠错笔记

> 配套脚本:`exercises/transformer/06_train_and_generate.py`
> 这是一份「初学者总结 → review 纠正」的对照笔记,帮你避开几个最常见的理解误区。

## 初学者的原始总结

- 给定一批句子,转换成为矩阵 `(batch, num_token, embedding_size)`
- 建立神经网络 MLP,每一层学习优化,计算 loss,梯度下降,减少 loss
- 跟传统 MLP 不同的是,用了多头 attention
- attention 使用了 QKV 结构,把输入投射到不同语义空间,softmax 求出概率最大值
- 最后的学习结果是高维

## 逐条 review

| # | 原始理解 | 评价 | 问题 |
|---|---------|------|------|
| 1 | 句子→矩阵 (batch, num_token, embedding) | ⚠ 基本对 | 漏了中间两步:先**分词成 token id 整数**,再**查表**变向量,还要**加位置编码** |
| 2 | 建 MLP,每一层学习优化,算 loss,梯度下降 | ✗ 有误 | 不是 MLP;不是"每层各自优化"而是**整个网络一次反向传播,统一更新所有参数** |

## 三个重点纠正

### ❌ 纠正 1:不是"每一层学习优化"(第 2 条)

神经网络**不是每层各自优化**:

```
  整个网络: 输入 ──forward──► 一个 loss
                              │
            ◄──backward── 一次性算出所有层每个参数的梯度
                              │
            optimizer.step() 同时更新所有层的权重
```

全网络共用**一个 loss**,反向传播一次把梯度传到每一层,所有参数**同步更新**。不存在"某一层单独学习"。

而且模型主体是 **Transformer Block**(attention + FFN + 残差 + LayerNorm),MLP(就是 FFN)只是 block 里的一个小部件,不是整体。

### ❌ 纠正 2:softmax 不是"求最大值"(第 4 条)

最关键的错误。softmax 做的是**把一组分数变成一个和为 1 的权重分布**,不是挑出最大那个:

```
  分数  [2.1, 0.3, 1.5]
         │ softmax (≠ argmax!)
         ▼
  权重  [0.55, 0.09, 0.36]   ← 和=1, 每个都保留, 只是大的占比高
         │ 用这组权重去"加权求和" V
         ▼
  output = 0.55·V₀ + 0.09·V₁ + 0.36·V₂
```

| | softmax(本题用的) | argmax(求最大值) |
|---|------|------|
| 输出 | 一个概率分布(多个值) | 一个位置(单个值) |
| 作用 | 算"关注每个 token 多少" | 挑唯一最高 |

> "求最大值"(argmax)只在**生成阶段选下一个字符**时才出现,且和 attention 里的 softmax 是两码事。

补充:Q/K/V 是同一份输入经**三个不同矩阵投影**出的三个"视角"(Q=我想找什么、K=我能提供什么、V=我的内容),"投射到不同语义空间"方向对。

### ❌ 纠正 3:"学习结果"指什么(第 5 条)

要区分两个东西:

```
  学习的结果(训练产物) = 所有权重矩阵的最终数值
                        (W_qkv, W_o, FFN, embedding 表... 共 15万个数)

  模型的输出(每次预测) = logits (B, T, vocab_size)
                        → softmax → "下一个字符是28个字符里每个的概率"
```

最终输出维度恰恰是 **vocab_size(本题=28)**,不是"高维"。真正"高维"的是中间的 `d_model=64` 隐藏向量。

## 修正后的简练理解(正确版)

- 句子先**分词成 token id**,查 embedding 表 + 加位置编码,变成 `(batch, num_token, d_model)` 矩阵
- 主体是 **N 个 Transformer Block 堆叠**(每个 = 多头 attention + FFN + 残差 + LayerNorm),不是单纯 MLP
- **attention 用 QKV**:同一输入投影出三个视角,Q·K 打分后 **softmax 成权重分布**,再**加权求和 V**(不是求最大值)
- 训练 = 整个网络**一个 loss、一次反向传播、统一更新所有权重**;目标是"预测下一个 token"(标签右移一位)
- **学习结果 = 训练好的全部权重**;每次输出是 **vocab 维的概率分布**,生成时才用 argmax/采样挑下一个字符

---

## 一句话总结

骨架抓对了(向量化 → 网络 → loss → 梯度下降、attention 用 QKV),主要改三个点:**网络是整体一起优化不是逐层、softmax 是加权不是取最大、最终输出是词表维的概率而非"高维"**。

## 附:06 实际训练结果(默认 3000 步)

```
  词表大小 vocab_size = 28        模型参数 = 154.9K (3层/d=64/4头)

  step 0:    loss = 3.4735   ← 随机初始化, 接近瞎猜
  step 150:  loss = 0.1129   ← 150步就暴跌(任务简单)
  step 2999: loss = 0.0633   ← 最终, 远 << 1
  参考: log(28) = 3.3322     ← 完全瞎猜的基线
```

生成续写(三个 prompt 都续对原文):

```
  'the q' →  'the quick brown fox jumps over the lazy dog. '
  'pack '  →  'pack my box with five dozen liquor jugs. pack'
  'how v'  →  'how vexingly quick daft zebras jump. the five'
```

> 这是**过拟合记忆实验**(数据少、模型小),证明的是"架构 + 训练闭环能跑通并学到东西",而非模型会"理解"语言。真实 LLM 只是把规模、数据、词表放大了千万倍。
