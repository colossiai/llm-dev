# 正向传播是计算差值loss， 反向传播是计算导数， 算出哪个参数对loss影响大？ 为什么计算导数可以推导出哪个参数影响大？


这是理解反向传播最关键的一步。

你的理解已经很接近了：

```text
前向传播：
参数 → 预测值 → Loss

反向传播：
Loss → 导数 → 参数
```

但要进一步理解：

> 为什么导数能告诉我们哪个参数影响大？

---

# 先看一个最简单的例子

假设：

```math
L(w)=w^2
```

Loss 完全由参数 (w) 决定。

---

## 在 w=2 时

Loss：

```math
L=4
```

导数：

```math
\frac{dL}{dw}=2w=4
```

什么意思？

---

把 w 稍微改一点：

```math
w=2.01
```

Loss：

```math
2.01^2
=
4.0401
```

增加了：

```math
0.0401
```

---

再改：

```math
w=1.99
```

Loss：

```math
3.9601
```

减少了：

```math
0.0399
```

---

所以：

```math
\frac{dL}{dw}=4
```

表示：

> w 每增加 1 个单位，
>
> Loss 大约增加 4 个单位。

导数本质上是在测量：

> **参数动一点，Loss 会变多少。**

---

# 为什么导数代表影响力？

想象两个人。

---

参数 A：

```math
\frac{\partial L}{\partial A}=100
```

参数 B：

```math
\frac{\partial L}{\partial B}=0.01
```

---

如果都只改一点：

```math
\Delta A = 0.001
```

则：

```math
\Delta L
\approx
100\times0.001
=
0.1
```

---

而：

```math
\Delta B =0.001
```

则：

```math
\Delta L
\approx
0.01\times0.001
=
0.00001
```

---

结果：

```text
A动一点
Loss变化很大

B动一点
Loss几乎不变
```

所以：

```math
|\partial L/\partial A|

>

|\partial L/\partial B|
```

说明：

> A 对 Loss 更敏感。

也就是：

> A 对结果影响更大。

---

# 神经网络里的含义

例如：

```math
y_{hat}=w_1x_1+w_2x_2
```

Loss：

```math
L=(y_{hat}-y)^2
```

反向传播算出来：

```math
\frac{\partial L}{\partial w_1}
=
10
```

```math
\frac{\partial L}{\partial w_2}
=
0.1
```

表示：

```text
w1 稍微动一下
Loss变化很多

w2 稍微动一下
Loss变化很少
```

因此优化器会更关注：

```math
w_1
```

---

# 导数不仅告诉你影响力，还告诉你方向

例如：

```math
\frac{\partial L}{\partial w}=5
```

正数。

说明：

```text
w增大
Loss增大
```

为了让 Loss 下降：

```text
w应该减小
```

---

再看：

```math
\frac{\partial L}{\partial w}=-5
```

负数。

说明：

```text
w增大
Loss减小
```

为了让 Loss 下降：

```text
w应该增大
```

---

因此：

```text
导数绝对值
=
影响有多大

导数符号
=
应该往哪个方向调整
```

---

# 梯度下降为什么成立

利用一个数学近似：

```math
L(w+\Delta w)
\approx
L(w)
+
\frac{dL}{dw}\Delta w
```

这就是泰勒展开的一阶近似。

如果取：

```math
\Delta w
========

-\eta
\frac{dL}{dw}
```

那么：

```math
L(w+\Delta w)
\approx
L(w)
----

\eta
\left(
\frac{dL}{dw}
\right)^2
```

因为：

```math
\left(
\frac{dL}{dw}
\right)^2
\ge 0
```

所以：

```math
L(w+\Delta w)
<
L(w)
```

（学习率 (\eta) 足够小时）

---

这就是梯度下降的理论基础。

---

# 用登山来直觉理解

把 Loss 想成山的高度。

参数 (w) 是你所在的位置。

```text
      山顶
       /\
      /  \
     /    \
----/------\-----
```

导数：

```math
\frac{dL}{dw}
```

其实就是：

> 当前地面的坡度。

---

如果：

```math
dL/dw = 20
```

说明：

```text
坡很陡
```

影响很大。

---

如果：

```math
dL/dw = 0.001
```

说明：

```text
地面几乎平
```

影响很小。

---

所以反向传播本质上是在回答：

> 对于网络里的每一个参数，
>
> **如果我把它拧动一点点，Loss 会变化多少？**

而导数正是这个问题的数学答案：

```math
\boxed{
\frac{\partial L}{\partial \theta}
=
\text{参数 }\theta\text{ 改变一点时，Loss 的变化率}
}
```

因此计算出导数以后，我们既知道：

* 哪些参数最重要（梯度绝对值大）
* 应该往哪个方向改（梯度正负号）
* 改多少合适（学习率控制）

这就是反向传播能够训练神经网络的根本原因。
