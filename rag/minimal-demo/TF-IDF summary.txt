  设计亮点

  两档配置,渐进式上手:

  ┌──────────────────┬───────────────────────────────────────────────────────┬─────────────────────────────────┬─────────────────┐
  │       配置       │                         命令                          │              依赖               │     何时用      │
  ├──────────────────┼───────────────────────────────────────────────────────┼─────────────────────────────────┼─────────────────┤
  │ 默认             │ uv sync && uv run python rag_demo.py                  │ sklearn + numpy                 │ 零下载,3 秒可跑 │
  ├──────────────────┼───────────────────────────────────────────────────────┼─────────────────────────────────┼─────────────────┤
  │ + 神经 embedding │ uv sync --extra neural && python rag_demo.py --neural │ + torch + sentence-transformers │ 看真实效果      │
  ├──────────────────┼───────────────────────────────────────────────────────┼─────────────────────────────────┼─────────────────┤
  │ + LLM 调用       │ python rag_demo.py --llm                              │ + .env 配 API key               │ 完整 RAG 流程   │
  └──────────────────┴───────────────────────────────────────────────────────┴─────────────────────────────────┴─────────────────┘
